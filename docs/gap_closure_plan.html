3调研核心发现（2025–2026 学术 × 工业）

三个并行调研代理 · 16+ 次检索 · 优先采信官方一手来源（arxiv.org / anthropic.com / pytorch.org / linuxfoundation.org / swebench.com）。

缺口 D

RAG 全链路

新建 Part 18 · 应用线 A1
  • Chunking 已有定论级方案：递归分块打底 + Anthropic Contextual Retrieval（每 chunk 生成上下文前缀再嵌入）——检索失败率 5.7% → 1.9%（-67%），官方全文数字齐备，可直接照抄成课程实验。
  • Reranker 由 cross-encoder 主导：Qwen3-Reranker 系列（Apache 2.0、instruction-aware）；ColBERT/late-interaction 在 SOTA 话语中边缘化。
  • “何时不该用 RAG”有实证：Google Self-Route——长上下文质量更高但约 23× 成本；阿里 LaRA 基准（11 模型×2326 查询）：无银弹；<200k token 直接塞 prompt 成为 context engineering 共识。
  • 评测：RAGAS 四指标仍是事实标准，2025–26 无新标准出现；MTEB 榜单被官方承认过拟合（~24% 英文集泄漏）→ 教“别迷信榜单”。
  • 教程取舍：GraphRAG / HippoRAG 2 / RAPTOR 只讲思想（KG 构建成本不划算，标选做）；不手写 ANN。
缺口 E

Agent / Function Calling

新建 Part 19 · 应用线 A2
  • 协议三层分工清晰：MCP（agent↔工具，生态增长 8000%，OpenAI/Google 2025 跟进）· A2A（agent↔agent，捐 Linux Foundation 后 150+ 组织）· AGENTS.md（agent↔代码库静态说明）。
  • 手写完全可行：OpenAI tools JSON schema 成全行业事实标准，开源模型 chat template 原生兼容 → agent loop ≈ 150 行。
  • 多智能体：炒作退潮——最佳教学素材是三方辩论：Anthropic orchestrator-worker（token ~15×）vs Cognition《Don't Build Multi-Agents》（上下文碎片化）vs LangChain 调和框架；机制结论：收益来自上下文隔离而非数量。
  • 评测现状：SWE-bench Verified 首破 80% 的是 Claude Opus 4.5（80.9%）；第三方榜单存在 5–15 分污染/脚手架膨胀 → 只引官方站。
  • 与 Part 17 衔接：GiGPO（NeurIPS 2025，verl-agent 实现，无 critic）在 2×4090 可训 Qwen2.5-1.5B——推理侧“玩懂”agent 后进 RL 闭环。
缺口 G

Scaling Law

Part 13 新增 00 章
  • 主线叙事现成：Kaplan 幂律（2020）→ Chinchilla L(N,D)=E+A/Nα+B/Dβ（~20 t/p，2022）→ 数据约束（R>4 epoch 饱和，Muennighoff 2023）→ 过训练时代（推理侧最优，Besiroglu 2024）。
  • 工业参照系震撼对比：Llama-3.1-8B 实训 1875 tokens/参数（vs Chinchilla 最优 ~25）——因为推理算力远大于训练。
  • 可对标课程：Stanford CS336 Assignment 3 就是“拟合 scaling law + 固定 FLOPs 找最优配置”；HF datablations 是可复用代码。
  • 教学坑（必须讲）：Kaplan 高估模型尺寸的部分原因是固定 LR/未逐模型调 schedule——cosine horizon=总 token 数；拟合用 Huber 损失（后期 loss 噪声大）。
  • 易扣分点：emergent abilities 之争（Schaeffer NeurIPS 2023 杰出论文）正好衔接 Part 8 评估学“指标选择影响结论”。
缺口 H

幻觉 / 安全对齐 + lm-eval 实操

Part 8 07 章扩节 + 脚本 11/12
  • 幻觉检测两族谱：黑盒一致性（SelfCheckGPT，EMNLP 2023 标准基线）vs 白盒 probe（Lookback Lens 2407.07071、SE Probes）；semantic entropy 上过 Nature（Farquhar 2024）——教学叙事价值极高。
  • 反直觉实验素材：GPT-4 报告 Figure 8——RLHF 显著损害校准（更自信地错）；“低温=更事实”是过时简化（任务相关）。
  • 安全新经典：refusal direction（Arditi 2024，单一方向介导拒绝，4090 可复现 diff-in-means）；Constitutional Classifiers（Anthropic 生产部署）。
  • 基准迭代：AdvBench/TruthfulQA 已过时（污染/饱和）→ HarmBench / JailbreakBench / FACTS Grounding。
  • 中国合规一页纸（面试向）：双备案制 + 2025-09 内容标识办法 + 新网安法 2026-01。
  • lm-eval 坑：v0.4.10 起 pip 默认不装 HF 栈（必须 extras）；中文生态归 OpenCompass；--batch_size auto 可能 OOM。
缺口 A

长上下文 YaRN

Part 7 脚本 11 扩展 + 脚本 13
  • YaRN 仍是 2026 生产默认项：Qwen3 用静态 YaRN（factor=4.0，config 一行）；DeepSeek-V3 预训练阶段用 YaRN + mscale 温度进代码。
  • 路线图全景：128K→1M = 位置侧（YaRN/DCA/LongRoPE）+ 注意力侧稀疏化 + KV 侧压缩（H2O/SnapKV）三轴正交。
  • 实现成本极低：HF modeling_rope_utils.py ~80 行可整体移植（NTK-by-parts ramp + 温度 √(1/t)=0.1·ln(s)+1）——正好接在已有 PI/NTK 实验之后。
  • 评测分层：2×4090 跑不动真 128K 评测（24GB 装不下 70B 的 KV）→ “迷你 RULER”合成 KV 检索 + 认知层讲 RULER（宣称 128K 多在 ~32K 失效）/ HELMET / LongBench v2（最佳仅 50.1%）。
  • 避坑：dim 用 head_dim 不是 n_embed；论文 α/β 与 HF beta_fast/beta_slow 命名相反；温度必须在 softmax 前生效。
缺口 F

Flash Attention 手写内核

Part 9 新增 05 章 + 脚本 09
  • 4090（sm_89）支持矩阵：FA2 ✅ · FA3 ❌（WGMMA 是 SM90 独有指令）· FlexAttention ✅（torch 2.6 已可用）· SageAttention INT4 恰是 4090 甜点（~3× FA2）。
  • 手写路径明确：Triton 官方 tutorial 06（FA2 参照实现）+ GPU MODE Lecture 12（Thomas Viehmann，从 PyTorch 循环逐级到内核，贴合课程阶梯风格）。
  • 合理验收线有依据：FlexAttention（PyTorch 团队深度优化）前向 = FA2 的 90% = Triton 路径上限 → 教学版承诺 SDPA 最优后端的 50–70% 合格、>85% 优秀。
  • 生产采纳证据：Meta TorchTitan（Llama 3.1 8B–405B 官方训练配方）用 FlexAttention 做文档掩码；推理引擎主力仍是 FlashInfer/PagedAttention。
  • 核心算法：online softmax（exp2+log2e 技巧）+ KV 分块外循环 + causal 三阶段分解（无 mask 块/对角块/跳过）。
