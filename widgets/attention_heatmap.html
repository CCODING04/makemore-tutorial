Self-Attention 热力图：一张表看懂"谁在关注谁"

A = softmax(QK^T/√d_k)。行 = 查询 q（第 i 个 token 在找），列 = 键 k（被看的位置），格子颜色深浅 = 注意力权重。悬停任意格子读数。
鼠标悬停任意格子查看该对 (q, k) 的注意力权重；试试关掉"因果 mask"或"√d_k 缩放"对比。

📌 这张图画什么

8×8 的注意力矩阵：第 i 行第 j 列的格子回答"第 i 个 token 应该从第 j 个 token 那里拿多少信息"。三种手工调制的头代表真实模型里自发涌现的三类典型模式——单点头、句首/自我头、语义共现头。训练前它们是随机的，训练后长成这样。

🔖 符号与标识符

q（行）查询：第 i 个 token 发出的"信息需求"
k（列）键：第 j 个 token 供比对的"标签"
格子值softmax 后的注意力权重；每行加和恒为 1（悬停可验证）
因果 mask上三角置 −∞ → softmax 后为 0：位置 i 看不见 j>i 的未来（decoder-only 并行训练的前提）
√d_k缩放：点积方差随维度涨到 d_k，除以 √d_k 拉回 —— 不缩放则 softmax 饱和成 one-hot（关掉开关看）
⟨bos⟩起始符：因果 mask 下它只能看自己，权重恒 1.00

🧭 试一试

  • Head 1 + 悬停第 4 行（sat）：权重最大在"cat"——"前一 token 头"其实是"语法主谓头"的雏形
  • 关掉 因果 mask：每行突然能看到右边的"未来"——训练可以并行了，但语义变了（这是 BERT 式双向）
  • 关掉 √d_k 缩放：各行几乎变成 one-hot——softmax 饱和，梯度消失，这就是"为什么要除 √d_k"的实验证据
  • 温度拉到 3.0：分布被抹平——和 P1 的 softmax 温度台是同一个机理
