有效学习方法

每章遵循"教程 → 脚本 → 作业"三段式循环。配合论文精读与面试资产积累，确保知识从理解到内化到输出。

三段式学习循环

每章包含 Tutorial（概念+代码+配图）→ Scripts（渐进式可运行代码）→ Assignment（带自动测试的练习题）。

  1. 阅读 Tutorial，理解核心概念与配图
  2. 跟着教程运行 Scripts，逐步实践
  3. 完成 Assignment 中的 TODO，运行 pytest 验证
  4. 通过费曼检验：能向别人讲清楚

论文三遍阅读法

每章配一篇代表论文，用三遍法精读。公式用 verify_paper_formulas.py 数值验证（已含 RoPE/DPO/GAE/LoRA/MinHash 等 12 项断言）。

  1. 第①遍：快读全文，抓住贡献与结构
  2. 第②遍：精读方法节，推导关键公式
  3. 第③遍：数值验证（边界检查 / 单调性检查 / 数值验证）

五项完成标准

判断"学完一个 Part"的五条硬标准，全部满足才算通过。卡壳时先对照参考答案再回看教程。

  1. 能解释核心概念（不看笔记）
  2. 能独立运行所有 scripts
  3. 能完成 assignment 并通过测试
  4. 能回答思考题
  5. 能向别人解释（费曼检验）

面试资产积累

每章产出面试可用的"硬数字"与"讲故事链"。叙事公式："我跑过，现象是 X，原因是 Y"——引用自己复现的实测数字。

  1. 硬数字清单：每章产出的实测数据加入复述清单
  2. 六条讲故事链：训练链/架构链/对齐链/推理链/分布式链/应用链
  3. 答题框架：每个概念按"直觉 → 公式 → 数字"三段复述
  4. 面试直通车：Part 11–14 每章含 4 问自测

加速通道

已有 PyTorch 基础者可跳过 Part 1–5 的教程阅读，直接从作业开始做——全绿即通过（验证代替学习）。

  1. 直接做 Assignment 1–5 的 TODO
  2. 运行 pytest，全绿即通过该 Part
  3. 未通过的题回看对应 Tutorial 章节
  4. Part 6 起必须完整阅读 Tutorial

每日节奏建议

工作日 1–1.5h + 周末 3–4h，周均 10–12h。每章学完当天写一段"我学到了什么"的复述。

  1. 工作日：阅读 Tutorial + 运行部分 Scripts（1–1.5h）
  2. 周末：完成 Assignment + 论文快读（3–4h）
  3. 学完每章：写 200 字复述（不看笔记）
  4. 每周日：回顾本周硬数字 + 讲故事链自问"为什么"
