## 费曼自检：ZeRO 三阶段（直觉 → 公式 → 数字）

**直觉**：16Ψ/参数 = 参数 2 + 梯度 2 + master 4 + 动量 4 + 方差 4。其中 12Ψ 优化器状态只在 `optimizer.step()` 时用、各参数互相独立 → 最先切（ZeRO-1）；梯度只在 backward 尾声短暂需要全量 → 其次切（ZeRO-2）；参数 forward/backward 随时要 → 最后切，切了就得 forward 前 all-gather 补齐（ZeRO-3，通信 ≈1.5×）。**一句话：按"谁的全量副本最不被随时需要"来决定切的顺序。**

**公式**（自答后核对 03 章表格与作业题 2，全部一致）：
- ZeRO-1 = 2Ψ + 2Ψ + 12Ψ/N = **4Ψ + 12Ψ/N**
- ZeRO-2 = 2Ψ + (2+12)Ψ/N = **2Ψ + 14Ψ/N**
- ZeRO-3 = **16Ψ/N**
- 恒等式：ZeRO-1 − ZeRO-2 = (2−2/N)Ψ ≥ 0，N 越大省越多（作业 Q3 的 (2−2/N)Ψ 与 03 章动手 1 的 (2/N−2)Ψ 是同一式子的两种写法 ✓）

**数字**（7B，N=8，GB 口径 1e9）：DDP 112 → ZeRO-1 38.5（4×7+12×7/8=28+10.5）→ ZeRO-2 26.25 → ZeRO-3 14。**自检锚点：N=1 时代回四条公式全部 = 16Ψ** ✓（python 复算：16/16/16/16）。扩展锚点：TinyGPT Ψ=6,298,624，16Ψ=100.8 MB、ZeRO-1@N=2=63.0 MB，与脚本 03 Part B 打印逐位一致 ✓。
