## 费曼自检：用「直觉 → 公式 → 数字」讲 self-attention

- **直觉**：每个 token 发三张"名片"——query（我在找什么）、key（我有什么）、value（若你看上我，我给你这些）。每个 token 拿自己的 query 去和所有**过去** token 的 key 对暗号，暗号越投缘，就拿越多对方的 value。
- **公式**：`wei = softmax( (Q Kᵀ / √d_k) + mask )`，输出 `= wei @ V`。其中 mask 是下三角外的 -inf（未来禁看），softmax 沿最后一维把每行变成和为 1 的权重，除以 √d_k 是防止 d_k 大时内积方差膨胀（≈d_k）把 softmax 推成 one-hot。
- **数字**：实跑（脚本 04，seed 1337）亲和力矩阵第 1 行 `[1, 0, ...]`（只能看自己），第 2 行 `[0.3141, 0.6859, ...]`（不再是 0.5/0.5 的均匀平均——权重是数据算出来的），每行求和=1。对照脚本 03 的 v2/v3 均匀版本 `[0.5, 0.5]`、`[0.333, 0.333, 0.333]`：同一个壳，wei 从"写死的 1/t"变成"q·k 算出来的"，这就是从平均到 attention 的全部区别。✅ 自检通过（公式我能默写，数字我能对上实跑；唯 √d_k 的方差推导我只能复述 assignment 里的版本，不敢说是自己推出来的）。
