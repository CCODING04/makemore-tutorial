## 卡点清单（🔴 优先）

### 🔴 硬卡点

**🔴1. one-hot × W 矩阵乘的"取行"等价性完全没讲** 
- 位置：`03_neural_network.md` §1/§2（1️⃣→2️⃣ 之间）
- 期望：给出 `[0,1,0] @ W = W 的第 1 行` 这类 3×3 手算例子，点明"xenc @ W 的每一行 = 把 W 里对应输入字符的那一行'抠'出来"，W 的每一行就是该字符作为上下文时的 27 个分数（Karpathy 原课的核心 aha 点）
- 实际：直接从 one-hot 定义跳到 `logits = xenc @ W`，中间零解释。我盯着这两节反复读了约 5 分钟仍不确定"W 和计数矩阵到底是什么关系"，最后自己写实验验证：`one-hot(1) @ W = [[10,20,30]]` 恰为 W 第 1 行（见附录 s1_probe 实验1）
- 什么能帮到我：一小段手算 + 一句"xenc@W 本质是查表（pluck）"

**🔴2. loss ≈ ln(27) ≈ 3.30 的均匀分布锚点在正文完全缺失** 
- 位置：`02_bigram_model.md` §5 与 `03_neural_network.md` §3 全文；仅 `assignments/assignment_1/README.md` 题 4 思考题提示里出现 `log(27) ≈ 3.296`
- 期望：训练前告诉我"模型瞎猜（27 字符均匀分布）时 loss = ln(27) ≈ 3.30，这是及格线"，这样我看到初始 loss 3.76、最终 2.45 才知道好坏与差距
- 实际：正文只有结果数字 2.45/2.47；脚本 06 打印"初始 loss（未训练）: 3.7590"，教程没有任何解读。我自问"3.76 说明模型初始是更好还是更差？"卡了约 10 分钟，自己做实验 2（全零初始化 → W 全 0 → exp(0)=1 → 均匀分布）实测 loss = 3.2958 = ln(27)，实验 3 才想通 randn 初始 3.7x > 3.30 是因为 logits 有方差 → softmax 偏离均匀 → 平均 NLL 变大

**🔴3. "训练后的 W.exp() 和计数矩阵 N 几乎一模一样"——实测不成立** 
- 位置：`03_neural_network.md` §4（169-177 行，正文只留注释"# 它们几乎一模一样！"，无可运行验证）
- 期望：等价性的准确表述 + 可运行的对比代码
- 实际：我自己训练 3000 步（无正则）实测：loss 收敛到 2.4544 ≈ 计数版 2.4540（loss 层面等价成立），但 **corr(W.exp(), N) 从 0.47 一路降到 0.34**，W.exp() 范围 [0, 89] vs N 范围 [0, 6763]，根本不是一个量级；真正单调收敛的是**行归一化后的分布偏差** max|P_w − P|：0.044 → 0.005。正确说法应是"W.exp() 行归一化后 ≈ P，即 W ≈ log N + 每行一个常数"。学生按教程字面去 print 对比，会以为是自己写错了
- 卡了多久：约 15 分钟（含两次实验）
- 什么能帮到我：把结论改成"分布等价而非数值相等"，并附对比脚本

## 费曼自检（直觉→公式→数字）

**NLL：能讲通。** 直觉：好模型应该给真实出现的数据高概率；一堆小概率连乘会下溢趋近 0，所以取 log 把乘法变加法；习惯上统一"最小化"，所以取负；不同长度的名字要可比，所以按 bigram 数取平均。公式：`NLL = -(1/n) Σ log P(ch2|ch1)`。数字：瞎猜 = ln(27) = 3.2958（实验 2 实测）；计数模型 = 2.4540（实验 4）；名字 andrejq = 3.4834，其中罕见组合 jq 一项 log = −7.98（脚本 05）——数字全部对得上，我讲得出。

**bigram→神经网络等价性：能讲通，但修正过教程的说法。** 直觉：神经网络只是把"数出来的计数"换成"可学习的分数"，one-hot 乘 W 相当于查表取出 W 的一行，所以 W 每行就是该字符的 27 个分数；exp 让分数变非负"伪计数"，行归一化就是 §3 学过的"计数→概率"，合起来就是 softmax。公式：`P = softmax(xenc @ W)`；最优解满足 `W ≈ log N + 每行常数`（softmax 行归一化对每行常数不敏感）。数字：训练 3000 步 loss 2.4544 ≈ 计数版 2.4540，行分布最大偏差降到 0.005；而 W.exp() 与 N 的数值相关只有 0.34——所以等价的是"分布"，不是"W.exp() ≈ N"。这个修正正是教程没讲清、我靠实验自己补上的。
