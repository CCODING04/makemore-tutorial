## 卡点清单（按痛的程度排序）

1. **【数学笔误·必改】02 章 "FLOP:byte = 2N:8" 与 85.33 自相矛盾。**
   正文写"（FLOP:byte = 2N:8，每字节只读一次）"但打印值是 85.33 FLOP/byte。
   验算：2N³/(3·4N²)=N/6=512/6=85.33，比例应为 **2N:12**；按 2N:8 算是 N/4=128。
   脚本 `03_naive_matmul.cu` 源码（min_bytes 含 A+B+C 三块）是对的，教程正文抄错。
   畏难学生在这里的第一反应是"是不是我算错了"，自我怀疑 10 分钟。
2. **【缺数字例·05 章最大短板】online softmax 推导（2.2 节）全符号、零数字。**
   l_new = l₁·α + l₂ 的三行等式链能跟上，但读完心里不踏实。我被迫自己造例子：
   x=[1,2,3,5]，块1=[1,2]、块2=[3,5]：m₁=2, l₁=1.3679；m₂=5, l₂=1.1353；
   α=exp(2−5)=0.0498；l_new=1.2034 —— 与整行一次算完全一致；
   若不重缩放直接 l₁+l₂=2.5032，错 2 倍。这个例子 5 行就能写进教程。
3. **【o 的重缩放一笔带过】** 2.2 节对 `o_new = o₁·α + o₂` 只有一句"输出的分子部分同理乘 α"，
   而它正是内核第 ⑤ 行 `acc = acc*α + p@v` 的直接依据——公式链条在最重要的地方跳了一步。
4. **【03 章列主序恒等式压缩】** "行主序缓冲按列主序读 = 它的转置"是对的（我用 2×2 验了：
   行主序 [1,2,3,4] 按列读 = [[1,3],[2,4]] = Aᵀ），但推导塞在一个 5 行引用块里，
   没有内存布局小图；且默认你记得 (A@B)ᵀ = Bᵀ@Aᵀ。对畏难学生这是两个隐藏台阶。
5. **【roofline 82 无来源】** "4090 roofline (~82 FLOP/byte)" 从哪来没讲
   （≈82 TFLOPS ÷ ~1000 GB/s）。一句话就能补上。
6. **【0.25 FLOP/byte 无推导】** naive 有效强度 0.25 的账（每输出 2N FLOP / 8N 字节读）
   藏在脚本注释里；作业题 3 的提示其实算了这笔账，但 02 章正文没回头呼应。
7. **【环境坑·教程已预告，不算缺陷】** 跑 08 遇到 `Ninja is required`：
   venv 里有 ninja 包但可执行文件不在 PATH。README 坑点表原话
   "pip install ninja 并**确保其可执行文件在 PATH**"精准命中，按提示解决。

## 费曼自检：online softmax（直觉 → 公式 → 数字）

- **直觉**：算 100 万个数的平均，不需要先把 100 万个数抄到一张巨纸上——维护"到目前为止的和"
  滚动更新。softmax 麻烦在分母要"整行的 exp 和"，而且数值稳定要求先减最大值；
  分块后最大值可能被新块刷新，所以还要多维护一个"到目前为止的最大值 m"，
  历史结果按"旧基准 → 新基准"折算。教程的平均值类比（05 章开头）我能原样讲给同学。
- **公式**（能默写）：m_new = max(m_i, rowmax(qk))；α = exp(m_i − m_new)；
  l = l·α + Σp；acc = acc·α + p@v；最后 out = acc / l。
  合法性根基：softmax 分子分母同乘 exp(−m_new) 结果不变，所以"减哪个最大值"可以事后修正。
  05 章教程把这句放在括号里——我会把它提为推导第一行。
- **数字**：教程没给，我自己补：x=[1,2,3,5]，块1=[1,2]：m₁=2、l₁=e⁻¹+1=1.3679；
  块2=[3,5]：m₂=5、l₂=e⁻²+1=1.1353；m_new=5、α=exp(−3)=0.0498；
  l_new = 1.3679×0.0498 + 1.1353 = **1.2034**，与整行一次算 1.2034**逐位一致**；
  反例：不重缩放直接 l₁+l₂ = 2.5032，错 2 倍。走过数字我才敢说"懂了"。
- **自评**：推导每步能跟上、动机清楚（α≤1、m 不变时零损耗的观察很好）；
  但"能跟上"≠"踏实"，缺的正是数字例那一块。
