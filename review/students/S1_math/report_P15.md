### 🔴 高

**卡 1：作业题 3 验收数值 21,043,712 与题面自己的公式矛盾**
题面步骤提示写明：`Linear(vision_dim→llm_dim) + Linear(llm_dim→llm_dim)，两层都含 bias`，验收写 `mlp2x_params(1024, 4096) == (1024*4096+4096) + (4096*4096+4096) == 21,043,712`。
我手算：1024×4096+4096 = 4,198,400；4096×4096+4096 = 16,781,312；**合计 = 20,979,712**，与代码验证一致。题面等式右边前半段（公式）与后半段（数值）自相矛盾，差 64,000 且无解释。学生按公式实现后看到 21,043,712 会先怀疑自己算错——对数学畏难学生这是最伤自信心的那类错误。

**卡 2：29,308 参数账漏了 PatchEmbed 的 312，"Stage 2 全部解冻"名不副实**
我逐组件分解（手算+代码双验证）：PatchEmbed conv = 3×24×2×2+24 = **312**；ViT(24)×2 = 9,648；Projector = 1,856；ToyLLM = 17,804（tok 384 + 2×block(32) 16,960 + ln 64 + head 396）。全模型 = **29,620**。脚本 Stage 2 打印 29,308 = 29,620 − 312，因为脚本 180 行 `trainable2 = vit + llm + projector`，**patch_embed 的参数从 Stage 1 到 Stage 2 从未被解冻、从未被训练**。正文却写"可训练参数（Stage 2）: 全部 29,308 参数"、"Stage 2 全部解冻"。账能对上，但"全部"二字是假的，且教程没提"图像前端固定不训"这个事实——初学者复算账本时会在这里卡死。

**卡 4：温度 τ 的符号在同一份材料里两种相反语义**

## 费曼自检：SigLIP vs CLIP（直觉 → 公式 → 数字）

**直觉**：CLIP 的 InfoNCE 是"N 选 1 单选题"——每张图在 batch 内 N 条文本里做 softmax，逼着把配对那条的分数顶到最高、其余 31 条全部压低，全局归一化让所有候选互相对抗，所以负例来自 batch、batch 越大题越难越好。SigLIP 是"N² 道独立判断题"——每一对 (图 i, 文 j) 单独回答"你们配吗"（配 +1 / 不配 −1），每道题只看自己，不看别的候选，所以不依赖 batch 大小。

**公式**（我自己的复述，教材里没有这版）：
- 记 S = scale · F_img @ F_txtᵀ ∈ R^{N×N}，两塔特征先 L2 归一化，S 是余弦相似度乘 scale。
- InfoNCE：`L = ½[CE(S, diag) + CE(Sᵀ, diag)]`；展开一行即 `−log[exp(S_ii)/Σ_j exp(S_ij)]`，CE 与标签=对角线这步就是它（教材跳过的那步）。
- SigLIP：`L = −mean( logsigmoid(T ⊙ S) )`，`T = 2I − 1`（对角 +1、其余 −1）；论文原版还有 bias 项（S + b），教材/脚本省略未声明。

**数字**（脚本 02 实测 + 我的手算/复现）：
- N=32：InfoNCE 负例/正例 = 31:1，均匀基线 ln 32 ≈ 3.47；实测 loss 4.155→1.968（初始高于基线，因 scale=10 放大了负相似度）。SigLIP 初始量级 ≈ −logsigmoid(±10) 的均值 ~0.7–1.6；实测 0.912→0.106。两者检索 top-1 都 100%。
- batch 8（负例只有 7）：我复现两者检索仍 100%——玩具任务太易，差异看不见；论文级数据下 InfoNCE 掉、SigLIP 用 1/4 batch 持平（教材引用，我无法在本机验证）。
- τ：scale 学到 16.21（CLIP 路径）/ 8.53（SigLIP），即温度 0.062 / 0.117；scale 越大 softmax 越锐——logits [2,1,0,0] 在 scale=1/5/10 下正例概率 0.610/0.993/1.000。
- 自评：三段都能脱稿讲清，卡过的点只剩教材 τ 记号需要我自己换算（卡 4）。
