## 费曼自检：轨迹级 GRPO（直觉 → 公式 → 数字）

- **直觉**：一组 8 条轨迹解同一道题，做对的轨迹组内"排名高"，它说的**每一句**（包括两次工具调用和最终答案，但不含观测——那是环境说的）都同乘一个正优势被强化；做错的整条一起被削弱。观测 token 不参与：环境的话不该由策略的梯度负责。
- **公式**：对同组 G 条轨迹，`A_i = (R(τ_i) − mean(R)) / std(R)`；loss = −Σ_τ Σ_{t∈assistant(τ)} log π(a_t|·)·A_i ÷ Σ_τ #assistant(τ)。（这是我补的精确写法——教程原文的 Σ 范围没写死，正是卡点 1。）
- **数字**（我自己算的，教程缺的正是这块）：奖励 [1,1,1,1,1,0,0,0] → mean=0.625；有偏 std=√(5×0.375²+3×0.625²)/8 ≈ 0.484（+1e-4 eps）；成功轨迹 A=(1−0.625)/0.484≈**+0.774**，失败轨迹 A≈**−1.291**（失败更"陡"是因为离均值更远）。全同组 [1,1] → 分子 0 → A=0 → 无梯度。实测数值验证：`adv.unsqueeze(1).expand_as(M)*M` 后观测位优势恰为 0，反向传播观测位梯度严格 = 0（我 scratch 里的梯度探针输出 `[0.65, 0.00, 0.37]`），教程公式与脚本口径一致。

**自检结论**：三段能讲通，但"公式"和"数字"两段都是我自己补的——教程只给了直觉和一行符号，费曼到第二段就断了。
