## 白板默写自测（先默写后对照，如实记录）

**1. DPO 损失（含 β 与隐式奖励）——通过**
默写：`L = -log σ( β[ (log π(y_w|x) - log π_ref(y_w|x)) - (log π(y_l|x) - log π_ref(y_l|x)) ] )`；隐式奖励 `r̂(x,y) = β·log(π/π_ref)`。
对照：与 03 章 L153-163、L289 逐符号一致 ✓。边界：β→0 时 β·logits→0，loss→ln2 常数、梯度→0——**策略停在原地不更新**（不是退化成 Bradley-Terry）；β→∞ 等价于去掉 KL 软约束、硬拉对齐，易 reward hacking。verify_paper_formulas 断言（起点 ln2、优势↑→loss↓）实跑通过。
（默认写时我把"β→0 退化成什么"第一反应写成"退化为 BT"，推了一遍梯度才纠正为"无梯度停更"——面试前要把这个边界练成条件反射。）

**2. GAE 递归式——通过**
默写：`δ_t = r_t + γ·V(s_{t+1}) - V(s_t)`；`A_t = δ_t + (γλ)·A_{t+1}`（episode 边界乘 nonterminal）。
对照：与 04 章 L96/L114-128 一致 ✓（教程代码里 `nonterminal = m[:,t+1]`、`lastgae = delta + γλ·nonterminal·lastgae` 我补写对了）。λ=0→单步 TD（高 bias 低方差）、λ=1→MC（低 bias 高方差）；γ=1.0, λ=0.95 为 LLM 常用（无终止状态）。verify 脚本两条退化断言 ✓。

**3. GRPO 组内优势——通过**
默写：`A_i = (r_i - mean(r_1..G)) / (std(r_1..G) + ε)`，同 prompt 的 G 个回答共享组均值 baseline，组内 advantage 均值 0、标准差≈1。
对照：与 04 章 L234-241、作业题 8 一致 ✓；04 章 "3+5=" 数值例（mean=0.5, std=0.58, adv=±0.87）可直接当面试板书素材。

**4. k3 KL 估计器为什么好用——通过（含自补推导）**
默写：`KL ≈ exp(log π_ref - log π) - (log π_ref - log π) - 1 = r - log r - 1`，其中 `r = π_ref/π`。
三优点（04 章 L276-279）：无偏（`E_π[r] = 1`，故 `E[r - log r - 1] = KL(π‖π_ref)`）、逐点非负（`x - log x - 1 ≥ 0` 对 x>0 恒成立，不需 clamp）、数值稳定/在 r≈1 处低方差（一阶项抵消，只剩二阶小量）。
对照：教程给三优点但未给无偏的期望论证——我自补的 `E[r]=1` 推导教程没有，**这是面试可加分的超教程点**。

## 面试资产清单（S3 冲刺直接可用）

- **对齐链（链 3）完整叙事**：BT `P(A>B)=σ(Δr)` → RLHF max E[r]−βKL → 闭式解 → 反解 r=β·log(π/π_ref)+β·logZ → Z 消掉 → DPO loss；追问弹药：β→0 无梯度停更、β→∞ 掉 KL 约束、隐式奖励差监控训练、ORPO/KTO 各省什么（ref 模型 / 成对数据）。
- **PPO 三防**：clip 防策略突变（ratio 越界截断）、GAE 在 bias-variance 间插值（λ=0 TD / λ=1 MC）、KL penalty 防遗忘 + entropy bonus 防模式坍缩。
- **GRPO vs PPO 一页话术**：去 Value Net 的理由（组均值=天然 baseline，省 ~50% 参数与 GAE 递推）、k3 三优点 + 自补的 `E[r]=1 ⇒ 无偏` 推导（超教程加分点）、RLVR 适用边界（可验证任务才免费可靠）。
- **推理优化手算包**：KV 公式 + 1.07→0.27→0.13→0.03 四级阶梯；碎片 41%→5% 模拟 vs 论文 60-80%→<4%（**主动区分简化模拟与论文语境，是诚实加分点**）；投机解码判据 u<pt/pd、E 公式、"大 batch 转 compute-bound 后不赚"；今日实测 α≈0.60/2.47 可现场复跑背书。
