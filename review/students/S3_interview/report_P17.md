## 白板默写自测（闭卷，如实记录）

**1. 多轮 RL 与单轮 RL 的 loss 口径差异（观测 mask 怎么进 loss）——默写成功。**
单轮：序列 = [user(mask=0) + assistant(mask=1)]，loss = −Σ_{assistant} logπ·A。
多轮：序列 = [user 0 → tool_call 1 → 观测 0 → tool_call 1 → 观测 0 → 最终答案 1]，整条轨迹一个 0/1 奖励，组内标准化优势**广播到全部 assistant token**，loss = −Σ(logπ·A)/#assistant_tokens；观测段 loss-mask=0，策略梯度不流过环境 token。关键区分（教程专门框注）：**loss-mask**（观测 token 不进 loss）≠ **内容遮蔽**（观测不进输入）；工业 verl/slime multi-turn = 观测进上下文 + loss mask，本玩具把两件事合并成一个开关，额外演示"观测含答案 → 复读捷径"的孪生问题。脚本实现口径：`A = advantages.expand_as(M) * M`，再除 `M.sum()` 归一。

**2. Echo Trap——默写成功。**
RAGEN（arXiv 2504.20073）提出的多轮 RL 特有稳定性陷阱：策略**熵坍缩到重复模板**（同样的工具调用循环往复），而**奖励曲线看不出来**（模板可能还拿低奖励）。发现：监控 rollout 熵 + 轨迹多样性（assignment 题 4 的去重比例是其单指标版；思考题 Q3 补刀：多样性高≠探索健康，要联合看熵与成功率）。缓解：**StarPO-S 三件套 = critic 辅助 + clip-higher + rollout 过滤**（其中 rollout 过滤建立在本课"全同组优势全零"性质上）。

**3. BC 冷启动解决什么——默写成功，且今天亲手复现了。**
解决**稀疏奖励死锁**：随机初始化策略采不出合法工具调用格式 → 奖励恒 0 → 组内 std=0 → GRPO 优势全零 → 无梯度 → 永远采不出（自锁）。即 R1 论文 cold start SFT 的玩具版。更深一层（本课独有洞察）：**冷启动的覆盖度和策略熵直接决定 RL 能否启动**——覆盖不足时未见组合全组失败，同样是零方差零梯度死锁（我复现：示范砍到 2 条，curve = 0.333×6 纹丝不动）。

三项全部写得出——教程的"概念检验 + 面试直通车"训练闭环有效。

## 面试资产清单（我能带进考场的东西）

1. **30 秒答"Agentic RL vs 单轮 RLVR 实现差异"**：多轮轨迹、观测 mask、轨迹级优势广播、异步 rollout、上下文管理——教程给的"答 3 个即合格"模板（01 章结尾 + assignment 面试直通车）。
2. **观测 mask 三重理由 + 孪生问题**：不是模型的话 / 浪费容量 / 幻觉工具结果；loss-mask≠内容遮蔽；"环境给的 token 不该承载策略梯度"（可引 Search-R1 retrieved-token masking）。
3. **BC 死锁链条（带自己的实测数字）**：覆盖不足 → 未见组合全零组 → std=0 → 优势全零 → 无梯度 → 永远采不出；我复现了 0.333×6 纹丝不动 → 40 步软策略推到 ~0.5，可以讲"我亲手把这个死锁复现出来"。
4. **Echo Trap 三段式**：症状（奖励正常但熵坍缩）→ 发现（熵 + 轨迹多样性，且多样性高≠健康）→ 缓解（StarPO-S 三件套）；零方差组"无区分度的组没有信息量"是性质不是 bug。
5. **判分漏洞自曝故事**：玩具判分取"轨迹最后数字"被观测冒充 → RLVR 三堵法（格式约束 / 工具协议 / 答案位置锚定）——展示"能审自己的 reward function"的工程素养。
6. **GiGPO 锚定状态直觉**：01 章玩具里 `multiply` 后的 `[user|call1|obs1]` 前缀是天然锚定状态——把 2505.10978 讲成具体例子而非名词。
