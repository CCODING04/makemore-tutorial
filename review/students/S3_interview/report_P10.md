## 白板默写自测（如实记录）

**1. DDP 梯度桶化为什么按反向顺序？——能写出。**
构造时按参数在 backward 中**梯度就绪的顺序**（≈参数注册顺序的逆序）分桶（默认桶上限 25 MB）。backward 从 loss 端往 embedding 走，最先就绪的是靠近输出头的层 → 第一个桶立刻异步 all-reduce，此时其余层的反传还在算，通信被计算盖住；全部桶发出后，backward 结束前只阻塞等最后一个桶。若按前向顺序分桶，第一个桶要等整个 backward 走完才就绪，重叠无从发生。toy 模型（628,161 参数 ≈2.5 MB < 25 MB）只建 1 个桶，所以小模型上"桶间重叠"根本观察不到——这正是教程说"toy 加速比不可信"的机制层原因。可辩护。

**2. ZeRO 三阶段各保存什么、省多少（7B/AdamW 算式）？——能写出。**
16 Ψ = bf16 参数 2 + bf16 梯度 2 + fp32 master 4 + fp32 动量 4 + fp32 方差 4。DDP 16Ψ；ZeRO-1 切 master/m/v → 4Ψ+12Ψ/N；ZeRO-2 再切梯度 → 2Ψ+14Ψ/N；ZeRO-3 再切参数 → 16Ψ/N。7B、N=8：112 → 38.5 → 26.25 → 14 GB（1e9 字节口径）。通信：ZeRO-1/2 与 DDP 同量级（"免费午餐"），ZeRO-3 ≈1.5×（forward all-gather + backward reduce-scatter）。恒等式：ZeRO-2−ZeRO-1 = 2Ψ(1/N−1) ≤ 0，N=1 时四条公式全退化 16Ψ（校验锚点）。可辩护。

**3. 1F1B 为什么比 GPipe 气泡小？——题目预设本身是陷阱，我写的是"纠正版"。**
按教程/作业的立场（assignment 思考题 Q5 明说）：**两者 bubble 公式相同**，都是 (p−1)/(m+p−1)，1F1B **不省气泡时间**；1F1B 交错 F/B 把激活驻留从 m 份降到 p 份——省的是显存，不是气泡。若面试官问"1F1B 为什么气泡小"，正确回答是指出前提不成立，再给 p=8、m<64 时 bubble>10% 的"何时气泡成主要矛盾"分析。教材立场一致且正确；本自测题的措辞（"为什么比 GPipe 气泡小"）恰好是这个经典误区的原样复述，已如实记录。

## 面试资产清单

- **一句话钩子**："DDP 的 all-reduce 是平均不是求和"——附三步线性性推导（和的导数=导数的和 → 分组重排 → 对照 DDP 实际操作），三前提：等大分片 / 均值 loss / 同起点。
- **账本心算**：16Ψ 五项构成；7B→112 GB（24G 卡训不动 7B 的完整答案）；ZeRO 表 4Ψ+12Ψ/N → 2Ψ+14Ψ/N → 16Ψ/N；N=1 全退化 16Ψ 锚点。
- **恒等式**（本次裁决产出）：ZeRO-2−ZeRO-1=2Ψ(1/N−1)≤0——"恒更省、省多少看 N"，可主动纠正面试官的"取决于 N"。
- **机制图**：桶化 all-reduce 与 backward 重叠时序；`_get_zeros_like_grad_buckets()` 验证 toy 只有 1 桶 → 解释 toy 加速比不可信 → MFU 用真实规模测。
- **no_sync**：省 K−1 次通信、第 K 次不能省（忘了切回 = 静默走歪）；loss/accum 的累加语义。
- **两个高频 bug**：DataLoader `shuffle=False`（防双打乱）、`sampler.set_epoch`（否则每 epoch 只见 1/N 数据）。
- **TP**：f/g 共轭算子、"每层每方向恰一次 all-reduce"、通信在层正中间遮不住 → 只放 NVLink 机内；QKV 按头切。
- **PP**：bubble=(p−1)/(m+p−1)；1F1B 省激活驻留 m→p 不省气泡（陷阱题正解）；p=8 深流水线 m≥64 + 梯度检查点。
- **配置推理链**：32 台 8 卡训 70B——机内 TP=8 → PP（1F1B）→ 剩余 DP 叠 ZeRO-1 → 激活不够再检查点。
- **工程 war stories**：NCCL p2p 卡死 → gloo+CPU 中转；gloo 不支持 AVG → SUM÷world；流水线汇总 loss 机械 ÷world 会恰好砍半；CPU 多进程 gloo 先调逻辑再加卡。
- **可复现数字**：4.380254（PP=单进程）、6e-07（TP 前向误差）、100.8/63.0 MB（记账断言）、20%/11%（气泡）、(2−2/N)Ψ（恒等式）。
