## 白板默写自测（先默写后对卷，如实记录）

1. **LLaVA 两阶段各训什么**：✅ 默写成功。Stage 1 特征对齐——冻结 ViT 与 LLM，只训 projector（mlp2x_gelu = Linear(vision→llm)→GELU→Linear(llm→llm)），558K 图文对，目标是生成式 CE；理由：随机投影器输出是"噪声 token"，两端同动会灾难性遗忘 + 冲散 CLIP 对齐。Stage 2 视觉指令微调——全部解冻（LLaVA-1.5 全参，资源紧可 LoRA），665K 指令数据，lr 2e-5。
2. **CLIP vs SigLIP 一句话 + 损失**：✅ 默写成功。一句话：CLIP 对 N×N 相似度矩阵按行/列 softmax（负例来自 batch，强 batch 依赖，CLIP 用 32768）；SigLIP 把它拆成 N² 个独立 ±1 sigmoid 二分类，无全局归一化，batch 缩到 1/4 仍持平。损失：`InfoNCE = 0.5*(CE(logits,labels)+CE(logits.T,labels))`；`SigLIP = -logsigmoid((2*eye(N)-1)*logits).mean()`；温度 `scale=exp(log_scale)` 可学习控锐度（脚本实测收敛到 16.21/8.53，起点 10）。
3. **图像 token 占上下文多少（算式）**：✅ 默写成功。`N_img = ceil(H/14) × ceil(W/14) （÷ 压缩率）`。LLaVA-1.5：336/14=24 → 24²=**576**；1024×768 pixel shuffle ÷4：74×55=4070 → **1017**。占窗口比：576/4096≈**14.1%**（4K 窗），1017/8192≈**12.4%**（8K 窗）——一张高清图吃掉一成以上上下文，所以动态分辨率必须配 token 预算控制。
