## 白板默写自测（不看材料，写完才对照）

### ① BN 前向 + 为什么训练/推理不同 —— 通过，带一处补课

训练时对每个特征维（沿 batch 维）：

```
μ_B = (1/N)·Σᵢ xᵢ        σ²_B = (1/N)·Σᵢ(xᵢ−μ_B)²   ← 有偏（÷N）
x̂ = (x − μ_B) / √(σ²_B + ε)      y = γ ⊙ x̂ + β
```

推理：不能用 batch 统计 → 用训练期 EMA 维护的 running stats：`running = (1−m)·running + m·batch`。三条理由：batch 可能 =1（方差无定义/为 0）；推理输出必须逐样本确定、不能依赖同批其他样本；running 统计是全局的更稳估计。

**默写时暴露的坑**：σ² 该有偏还是无偏、running_var 里存的哪个版本——材料没教，自查补课（=K1）。面试官若追问这里，靠教程会翻车。

### ② Kaiming 方差来历 —— 第一次卡壳，自推后通过

前向：`y_j = Σₖ W_jk x_k`，x 各分量独立同方差 σ_x²，则 `Var[y_j] = fan_in · σ_W² · σ_x²`。要 `Var[y]=Var[x]` 就令 `σ_W = 1/√fan_in`。gain 修的是激活函数本身造成的方差收缩：tanh 在 x~N(0,1) 下输出 std≈0.6，收缩要补回来 → gain≈1/0.6=5/3；ReLU 砍掉负半轴、方差减半 → 补 √2（He init：σ_W=√(2/fan_in)）。合成：`std(W) = gain/√fan_in`。

**暴露的坑**：这个推导教程一个字没有（只有练习 3 的一句提示）。S3 第一次默写只能背"5/3"数字说不出理——按"写不出=没被教会"的标尺，此处判**未被教会**，需正文补推导。

### ③ 激活均值 0 方差 1 为什么重要 —— 通过

(a) tanh 在 ‖preact‖ 大时 |tanh|→1，局部梯度 1−t²→0，多层连乘梯度消失——实测证据：病态初始化饱和率 65–70%，Kaiming 后 ~3%；(b) 各层方差守恒让信号和梯度的尺度在深度上不爆炸不消失；(c) 输出层 logits≈0 → softmax 均匀 → 初始 loss=ln(27)≈3.30，训练不浪费前几步纠错；(d) 均值偏移会让 tanh 工作区偏在饱和侧。这条教程教得最扎实，三处实验证据齐备，可直接讲。
