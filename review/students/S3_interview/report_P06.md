## 二、卡点清单（按严重度排序）

1. **ppl/困惑度概念在 Part 6 零覆盖**（最大缺口）。roadmap 节点 6 学习验证明确要求"训后 ppl≈9-11（指南硬数字）"，但 `grep -rn "ppl|困惑度|perplexity"` 在教程 5 个 .md + 7 个脚本中**零命中**。事实上 CPU 版最终 val 2.23 → exp(2.23)=9.3，恰好落在 9-11 区间，GPU 版 1.48 → 4.39——素材全在，就差一次 `ppl = loss.exp()` 的换算与一段定义。学生靠教程**无从自查**这个硬数字。
2. **pre-norm"为什么稳"没有论证**。03 章只说"现在更常见/现代标准""顺序很重要，别写反"。roadmap 要求"能解释残差 + pre-norm 为什么稳（衔接节点 3 的归一化坐标系）"——残差那半 ✅（Part 4 加法梯度规则回链，讲得很好），pre-norm 那半 ❌（没有任何稳定性机理论述，也没真正"衔接节点 3"）。
3. **Multi-Head"各头在学什么"停在类比**。02 章用"想找元音/位置/标点→多个话题通道"+分组卷积回答了"为什么要多头"，但没有任何一处让学生**观察**某个头的 wei 实际在关注什么（哪怕打印某一头对元音字符的注意力热区）。面试追问"你训练的 4 个头分别学到了什么"时，教程没有给出可复用的观察实验。
4. **07 脚本在 GPU 机器上与教程叙述脱节**。脚本用 `CPU_MODE = not torch.cuda.is_available()` 自动选模式：本机实跑直接进 **GPU 完整版**（10,788,929 = 10.789M 参数、5000 步、实测 step2000 val 1.5016，156 秒），而教程 03 章按"我们没有 GPU，主动缩小规模"叙述（0.112M、150 步、≈2.80、"<30s"）。带 GPU 的学生看到的数字与教程**完全对不上**；且首跑无 `-u` 时 stdout 全缓冲，**3 分钟内零输出**，体感是"脚本卡死"（我第一次跑就被迫按 3 分钟超时中断，exit=124，日志 0 字节）。GPU 完整版全程约需 6.5 分钟，教程/脚本均未提示。
5. **"标出 5 处与原论文不同"未清单化**。roadmap 论文验证项要求"不看原文画出 decoder-only block 数据流，标出 5 处与原论文不同（pre-norm 等）"。教程 03 章明确讲了 pre-norm vs post-norm（1 处），04 章 nanoGPT 走读的 GeLU/batched-MHA/权重分组/scaled-init/weight-tying 是"nanoGPT 与**我们的代码**的不同"，不是"与**原论文**的不同"，两者混在一起，学生拼不出这张 5 条清单。
6. **个别"实跑的真实结果"不可复现且未标 ≈**。如 02 章亲和力矩阵示例（教程第 2 行 [0.5141, 0.4859]，实跑 [0.3141, 0.6859]；末行 0.1136… vs 0.1339…）、04 章 step0 loss（教程 4.2351/4.2337 vs 实跑 4.2328/4.2301）。定性结论（数据依赖、≈2.39）不受影响，但"真实结果"的措辞让较真的学生复现不上时会自我怀疑。
7. **（弱）"加权均值可视化"是打印级**。roadmap 说"脚本 03/04：attention trick 的加权均值可视化"，实际是终端打印矩阵（无 matplotlib 图）。作为"可视化"勉强算数，观感打折扣。

## 五、白板默写自测（TOP8 #1，合上教程完成）

**默写产物**（scratch/S3_whiteboard.py，写完后才允许自己对照教程）：

```
形状链：x(B,T,C) → k,q,v=(B,T,hs) → wei=q@k^T·hs^-0.5 (B,T,T)
       → masked_fill(tril[:T,:T]==0, -inf)   ← mask 在 scale 后、softmax 前（判卷点）
       → softmax(dim=-1) 行和=1 → out=wei@v (B,T,hs)
多头：head_size = n_embd//n_head；cat(-1) → proj(hs*n_head→n_embd) 回残差通路
Block（pre-norm）：x = x + sa(ln1(x)); x = x + ffwd(ln2(x))；顶层另有 ln_f
细节：Linear bias=False；tril 用 register_buffer（不可训练、随 to(device)）
```

**属性测试（默写代码直接跑）**：shape 保持 ✅ / softmax 行和=1 ✅ / 严格上三角=0 ✅ / 残差恒等（参数清零后 Block(x)≈x）✅ —— 与作业题 4/5 的测试口径一致。

**"为什么除 √d_k"口述**（默写后自述，3 层）：① q,k 为 unit gaussian 时内积方差 ≈ d_k（d_k 个独立同分布项之和）；② 方差大 → softmax 喂进大值 → 坍缩 one-hot → 初始化时每个 token 只盯一个 token，通信失效、梯度也尖；③ 除以 √d_k 把方差拉回 ≈1，保护初始注意力"扩散"，聚焦留给训练去学。**数值证据**：head_size=16 实测 q·k 方差 15.89≈16，/4 后 0.99≈1；教程的 vals×8 演示（[0.20,0.15,0.25,0.17,0.23]→[0.12,0.01,0.58,0.02,0.26]）逐位复现。

**pre-norm Block 数据流口述**：tok_emb+pos_emb → N×(x=x+MHA(LN(x)); x=x+FFN(LN(x))) → ln_f → lm_head。通信(attention)与计算(FFN per-token)分工；残差通路全程只经加法 → 梯度 ≈1 直达输入（Part 4 加法均分梯度）。

**结论：被教会了。** 易错点自查清单（默写时真实犹豫过的位置）：tril 需 `[:T,:T]` 裁剪、mask 必须在 softmax 之前、cat 之后必须 proj、`wei` 行 softmax 用 dim=-1。犹豫均 <10 秒自行解决。

## 九、面试资产清单（TOP8 #1 讲法素材，按使用场景归档）

**A. 白板默写包（TOP8 #1，判卷点已标）**
- 30 秒开场："attention = token 之间按数据依赖的亲和力做加权通信"；K/Q/V 三句话比喻（key=我有什么 / query=我在找什么 / value=若你选我，你拿走的是 value，不是原始 x）
- 形状链四步：`(B,T,C)→Linear→(B,T,hs)→q@kᵀ·hs^-0.5→(B,T,T)→mask+softmax→wei@v→(B,T,hs)`
- **判卷点**：`masked_fill(tril[:T,:T]==0, -inf)` 在 softmax **之前**；行 softmax `dim=-1`；多头 `head_size=n_embd//n_head`，cat 后必须 `proj` 回 `n_embd` 才能进残差
- 加分细节：`bias=False`（投影不需要）；`register_buffer` 存 tril（非参数、随设备迁移）；nanoGPT 的 4D batched 版 `(B,nh,T,hs)` 与逐头 cat **数学等价**、只是把头塞进 batch 维

**B. √d_k 标准答法（3 层 + 2 个数字）**
方差论证（d_k 项求和→方差 d_k→softmax 尖锐化→/√d_k 回 1→保护初始扩散）；数值证据：head_size=16 实测方差 15.89→0.99；softmax 放大演示 [0.20,0.15,0.25,…]→[0.12,0.01,0.58,…]。追问"为什么不除 d"：√ 是为了让方差（二阶矩）而非标准差归一。

**C. 演进故事链（"你从这个 Part 学到什么"的标准答案）**
bag-of-words 平均（v1-v3 等价）→ 单头 2.39 → 多头（分组卷积类比）→ +FFN（通信/计算分工）→ +残差（加法梯度→超高速公路）→ +pre-norm LN → GPU scale-up 1.48。数字链：**ln65≈4.17 → 2.50 → 2.39 → 2.23 → 1.48；ppl 65→12.2→9.3→4.39（ppl 换算系本人自查补齐，教程未教）**。

**D. 架构选型弹药（ Decoder-only 为什么赢）**
