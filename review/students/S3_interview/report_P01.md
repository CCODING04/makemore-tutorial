## 五、白板默写自测（合上教程）

**默写 1：bigram 计数模型 → 概率矩阵流程** —— ✅ 一次写出：
读 names.txt → 字符表 26 字母（sorted）+ `.`=0 → stoi/itos → 每词 `['.']+list(w)+['.']` →
`zip(chs, chs[1:])` → `N[ix1,ix2]+=1`（27×27 int32）→ `P=(N+1).float(); P/=P.sum(1,keepdims=True)`
→ 第 i 行 = P(下一个字符 j | 当前字符 i)。keepdims 陷阱（(27,27)/(27,) 会按列广播全错）记得。
**结论：这条主线教程教会了。**

**默写 2：NLL 公式 + 为什么取负** —— ✅ 一次写出：
`NLL = -1/N Σ log P(xᵢ)`；似然 = bigram 概率连乘 → 一堆 <1 的数连乘下溢 →
log 把乘法变加法（数值稳定）→ 优化惯例是"最小化"，似然要最大化，故取负；
log 似然 ≤ 0（概率≤1），NLL ≥ 0 越小越好；取平均使不同规模数据集可比。
**结论：教程"概率相乘→取 log→相加→取负"链条 + 方向表格有效。**

**默写 3：计数版与神经网络版为什么等价（完整讲法）** —— ⚠️ 第一遍有两处卡壳，修正后写全：
- 正确讲法：one-hot(x) @ W 就是**查 W 的第 x 行**（第一遍漏了这层）；softmax(该行) 的
  `exp` 就是"伪计数"，行归一化后 = 概率；训练最小化平均 NLL = 最大化 log 似然；
  计数版行归一化频率正是多项分布 MLE 的闭式解。两者优化同一目标（无正则时），
  最优解满足 softmax(W 行)=P 行，即 W 行 = log P 行 + 行内任意常数（softmax 行内平移不变，
  第一遍照教程写成 W*=log(N)，自己意识到不精确，见 K5）。
- 卡壳点 2：脱口而出"L2 完全等价于 N+1"，回想后修正为"类比：都是把分布往均匀拉；
  严格说 L2=高斯先验、加法平滑=Dirichlet/计数先验"（K6）。
**结论：等价性"能讲出来"，但教程给的版本有两处不精确，全靠我自己补课才严密——
若我只读教程不实跑，面试会带着 log(N) 和"完全等价"两个错误去。**

## 九、面试资产清单（本节点新增，已入复述清单）

**硬数字**（每条都实跑验证过）：
- ln(27) ≈ **3.296** = 均匀分布初始 loss（W 全零实测 3.2958）——"初始 loss 诊断"第一锚点

- 数据规模：32,033 名字 / 196,113 字符 / 228,146 bigram / 27×27=729 参数 / lr=50
