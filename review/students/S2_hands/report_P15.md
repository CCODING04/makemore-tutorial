## 卡点清单（按严重度排序）

1. **【文档 bug·高】assignment.md 题 3 验收标准数字错误**：写的是 `... == 21,043,712`，但表达式 `(1024*4096+4096) + (4096*4096+4096)` 实际等于 **20,979,712**（差 64,000）。测试代码以表达式为准（`want = 20,979,712`），按公式实现能 PASS；但按题面数字心算/硬编码的学生必卡（我验算了三遍才确认是文档错）。
2. **【教程内部矛盾·中】教程 01 练习 2 步骤提示与脚本/作业结构不一致**：提示写 `Linear(d_v, d_l*2) → GELU → Linear(d_l*2, d_l)`（24→64→32，3,680 参数），而脚本 `Projector` 与作业题 3 的 mlp2x_gelu 是 `Linear(24→32)+GELU+Linear(32→32)`（1,856 参数）。教程正文/形状账本/参数账全部按 1,856 讲，唯独练习 2 提示相反；按练习 2 写作业，题 3 的参数账对不上。
3. **【预期管理缺失·中】两个"实验题"的预期现象在玩具设置下均未复现**：
   - lr 3e-3→3e-2（作业称"观察对齐被冲垮"）：实测 lr=3e-2 最终 loss 1.824 反而略优于 3e-3 的 1.837，末 50 步 std 0.0026 vs 0.0124（更稳）。玩具任务太简单（2 条固定样本），冲不垮。
   - batch 32→8（作业称观察 InfoNCE 小 batch 变差）：batch=8 时 InfoNCE 检索仍 100%、loss 0.010 甚至更低。且 batch 不同时 CE 的理论下界 log(N) 不同（log8=2.08 < log32=3.47），loss 绝对值不可直接比，教程未提示。
   学生照做会怀疑自己抄错代码。建议各加一句"玩具数据简单，可能观察不到明显差异"。
4. **【措辞不严谨·低】教程 01 "Stage 2 全部解冻（29,308 参数）"**：脚本 `trainable2` 只含 vit+llm+projector = 29,308，**PatchEmbed（312 参数）不在优化器里**（全部应为 29,620）。数字本身与脚本输出一致，但"全部"二字不准。
5. **【小不一致·低】温度初始值**：教程 02"错误 1 解法"建议 `log(1/0.07)`（CLIP 默认），脚本 02 实际初始 `log(10.0)`（τ=10）。初学者对照会疑惑。
6. **【小不一致·低】教程 01"最佳实践·两阶段配置"表**（lr 1e-3 / 2e-5）与脚本实际（3e-3 / 1e-3）不同且未注明表中是 LLaVA 论文语境、脚本是玩具设置。
