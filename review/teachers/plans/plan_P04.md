**数学定性实验（隔离 BN 子图，float32 对拍 autograd）**：
- 前向用**有偏方差** `/n`（本仓库 scripts 01-06 全部如此：`bnvar = bndiff2.mean(0)`）：
  - 式 A（含 `n/(n-1)`，即教程 03 / 脚本 05 / 作业 Q4 给的公式）→ err = 6.8e-3 ❌
  - 式 B（不含 `n/(n-1)`）→ err = 6.0e-8 ✅
- 前向用**无偏方差** `/(n-1)`：式 A → 1.2e-7 ✅；式 B → 6.5e-3 ❌
- **结论：`n/(n-1)` 属于无偏方差前向；仓库前向是有偏 → 教程/脚本/作业三者给的「一行公式」与自身前向不自洽，任何照做的学生都无法满足自己作业「误差 < 1e-5」的要求。** 这是 P0 级数学错误（n=32 时 4.56e-05 恰好略超阈值，容易被误当浮点噪声放行——作业 README 思考题 Q2 甚至会把这 4.56e-05 误解释为「正常浮点误差 ~1e-7」量级）。
- 修复方向（二选一，留汇诊裁决）：(a) 公式去掉 `n/(n-1)`（改动最小：03 章 1 处、脚本 05 两处、脚本 06 一处、作业 Q4 骨架与预期值）；(b) 前向改无偏 `/(n-1)`（牵动 02 章 Step12 推导与脚本 02/03/05/06，工作量大）。**倾向 (a)**，并同步修正「Bessel 校正」的表述（见 C1-F）。
