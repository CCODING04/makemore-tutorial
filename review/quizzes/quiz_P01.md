# 测验 · Part 1（Bigram 字符级语言模型）

> 依据：本 Part 学习目标与教程正文。建议先完成作业再自测；每题附答案与教程锚点。

## 测验（5 题）

**Q1（概念）** Bigram 模型对语言做了什么核心假设？构建计数矩阵时为什么要在每个名字首尾各加一个 `.`？

- **答案**：假设"下一个字符是什么，只取决于当前这一个字符"——一阶马尔可夫链，没有记忆。`.` 同时充当开始符与结束符：加在开头，矩阵第一行才能统计"哪些字母常作为名字开头"；加在结尾，模型才能学到"何时停下"。只加开头不加结尾，模型永远学不会终止生成。
- **锚点**：教程 02_bigram_model.md §1 Bigram 是什么；assignment_1/README.md 题 1 思考

**Q2（诊断）** 把概率归一化写成 `P /= P.sum(1)`（漏掉 `keepdims=True`）会发生什么？

- **答案**：`P.sum(1)` 形状为 `(27,)`，按广播"从右向左对齐"规则会被当作 `(1, 27)`，除法变成**每列**和为 1，而不是想要的每行为 1。正确写法 `P.sum(1, keepdims=True)` 得到 `(27, 1)`，沿行方向广播。这个 bug 不报错、loss 也能算，只有采样质量悄悄变差，必须用逐行 `P.sum(1)` 是否为 1 来验证。
- **锚点**：教程 02_bigram_model.md §3 从计数到概率（Broadcasting 速成 / 为什么需要 keepdims）

**Q3（对比）** 计数版与神经网络版 Bigram 为什么最终得到同一个模型？既然等价，神经网络版的意义何在？

- **答案**：两者都在对同样的数据做最大似然估计（MLE）：计数法直接给出闭式解（行归一化的频率），神经网络通过梯度下降最小化 NLL 逼近同一个解。课程实测计数法平均 NLL 约 2.45，神经网络训练后约 2.4901，差距只来自随机初始化与有限步优化。神经网络的意义在**可扩展性**：上下文加长时计数矩阵组合爆炸且稀疏，而网络只需微改结构。
- **锚点**：教程 03_neural_network.md §4 神经网络版 vs 计数版；§1 构建训练数据开头的"可扩展性"问答

**Q4（数字）** 这个任务里"均匀瞎猜"的损失基线是多少？训练好的 Bigram 实测能降到多少？

- **答案**：27 个字符等概率时交叉熵为 $\ln 27 \approx 3.296$；计数版 Bigram 平均 NLL 约 2.45；神经网络版教程记录约 2.47、作业实测 2.4901。换底成 $\log_2$ 后 NLL 直接对应"每字符平均需要多少 bit 编码"。2.45 就是"只看 1 个字符"模型的极限，生成质量受上下文长度限制。
- **锚点**：教程 02_bigram_model.md §5 评估模型质量：NLL Loss；assignment_1/README.md 题 4 思考与话术卡 Q1/Q2

**Q5（概念）** 描述从概率矩阵 $P$ 采样生成一个名字的完整流程。固定随机种子 `seed=2147483647` 的作用是什么？

- **答案**：从起始符 `.`（索引 0）开始，循环取出当前字符对应的行为 $P[\mathrm{ix}]$，用 `torch.multinomial` 按该分布抽一个索引（加权抽奖），抽到 0（`.`）即结束，否则拼接字符继续。固定种子让采样序列可复现——机器学习实验中可重复性是对比实验与调试的前提。Bigram 的采样产物（如 junide、cony，甚至单字母 `p`）暴露了它上下文只有 1 个字符的局限。
- **锚点**：教程 02_bigram_model.md §4 采样生成名字

## 闪卡（正/背）

| 正面 | 背面 |
|---|---|
| Bigram 模型的核心假设 | 下一个字符只依赖当前字符（一阶马尔可夫链）；上下文长度 = 1 |
| 为什么名字首尾都要加 `.` | 统一的起止符：开头教"以什么字母开头"，结尾教"何时停止"，且每个名字的 bigram 序列闭合 |
| 计数矩阵 N 的形状与含义 | $27 \times 27$（26 字母 + `.`），`N[i][j]` = 字符 i 后跟字符 j 的次数 |
| 行归一化的正确写法 | `P = N.float(); P /= P.sum(1, keepdims=True)`；`keepdims` 保住 `(27, 1)` 才能按行广播 |
| 为什么用 NLL 而不是似然做 loss | 概率连乘会数值下溢；取 log 乘法变加法；取负统一为"最小化"；NLL 越小越好 |
| 均匀分布基线与 Bigram 实测 | $\ln 27 \approx 3.296$；计数版约 2.45，神经网络版约 2.4901 |
| Laplace 平滑是什么 | 所有计数 +1（或 +λ）：从未出现的 bigram 概率不再为 0，避免 $\log 0 = -\infty$；加得越多分布越均匀 |
| L2 正则化对应计数法的什么操作 | `0.01 * (W**2).mean()` 压小 W 与 logits，softmax 输出趋向均匀，等价于 `N + λ`；用 `mean()` 是为匹配 NLL 量纲 |
| 采样如何终止与复现 | 从 `ix=0`（`.`）出发，`torch.multinomial` 按行抽样，抽到 0 结束；固定 `seed=2147483647` 可复现 |
