# 测验 · Part 2（MLP 与 Embedding）

> 依据：本 Part 学习目标与教程正文。建议先完成作业再自测；每题附答案与教程锚点。

## 测验（5 题）

**Q1（数字）** `block_size=3`、`n_embd=2` 时，名字 `emma` 展开成几个训练样本？写出从输入索引到 logits 的完整形状链。

- **答案**：5 个样本（`...→e`、`..e→m`、`.em→m`、`emm→a`、`mma→.`），对应 `X=[[0,0,0],[0,0,5],[0,5,13],[5,13,13],[13,13,1]]`。形状链：`X (N,3)` → `C[X] (N,3,2)` → `view (N,6)` → `emb_cat @ W1 + b1`（`W1 (6,100)`）→ `tanh (N,100)` → `W2 (100,27)` → `logits (N,27)`。`C[X]` 与 `F.one_hot(X, 27) @ C` 数学等价，但直接查表省内存省计算。
- **锚点**：教程 01_introduction.md §数据集准备：block_size=3；02_mlp_architecture.md §C[X] 高级索引详解 / §view(-1) 详解

**Q2（对比）** Train / Dev / Test 三个集合各自承担什么职责？课程如何划分，为什么 Test "神圣不可侵犯"？

- **答案**：全部 32033 个名字按 80/10/10 划分（约 25626 / 3203 / 3204），先 `random.seed(42)` 打乱保证可复现。Train 反复训练模型参数；Dev 用来调超参数（学习率、`n_embd`、`block_size`）；Test 只在最终报告时用一次——拿 Test 调参等于"考试前看到了答案"；反复对 Dev 调参，Dev 也会被间接"过拟合"。
- **锚点**：教程 01_introduction.md §Train / Dev / Test 划分

**Q3（数字）** 全量梯度下降和 Minibatch SGD 差别在哪？课程的学习率是怎么搜出来、怎么衰减的？

- **答案**：全量数据约 22 万样本（228146），全量每步要做 22 万次前向 + 反向，准但慢；Minibatch 每次随机抽 32 个样本算近似梯度，快但带噪声——噪声反而有助于逃离局部最优。学习率搜索：`torch.linspace(-3, 0, 1000)` 取指数 `10**lre`，即在 0.001 到 1.0 之间试 1000 个学习率，loss 最低点附近约 0.1 就是好学习率；训练到平稳后衰减到 0.01 继续降 loss。
- **锚点**：教程 03_training_and_eval.md §Minibatch SGD / §学习率调度

**Q4（诊断）** `train loss=1.5 / dev loss=2.5` 与 `train loss=2.5 / dev loss=2.6` 分别说明什么？本课程的 MLP 更可能是哪种？

- **答案**：前者是**过拟合**（train 很低、dev 高很多，模型在背训练集），要加数据或正则；后者是**欠拟合**（双双偏高、差距小，模型容量不够），要加大模型或延长训练；健康状态是 train 约 2.1、dev 约 2.2 的小差距。本课程 MLP 参数量约 3500，远小于 22 万样本，所以更可能是欠拟合而非过拟合。
- **锚点**：教程 03_training_and_eval.md §过拟合诊断（三种情况）

**Q5（概念）** 训练好后，如何从 MLP 逐字符采样生成一个新名字？为什么效果明显好于 Bigram？

- **答案**：`context` 初始化为 `[0, 0, 0]`；每次把 `context` 查 embedding、前向得到 27 维分布（`F.softmax`），`torch.multinomial` 抽一个索引 ix，然后 `context = context[1:] + [ix]` 滑动窗口更新；抽到 0（`.`）结束。因为模型每步看 3 个字符的上下文（而非 1 个），采样产物（mora、kiah、mel 等）明显更像真名。
- **锚点**：教程 03_training_and_eval.md §采样生成

## 闪卡（正/背）

| 正面 | 背面 |
|---|---|
| Embedding 矩阵 C 的形状与本质 | `(27, n_embd)` 可学习查表矩阵；`C[X]` 按整数索引取行，等价 one-hot 乘 C 但零拷贝高效 |
| block_size 是什么 | 上下文长度：用多少历史字符预测下一个；=1 时退化为 Bigram；课程按 Bengio 2003 取 3 |
| `view(N, -1)` 的 -1 是什么 | 让 PyTorch 自动推断该维度：总元素数除以已知维度；3 个 2 维向量拍成 6 维；`view` 要求内存连续，`reshape` 更灵活 |
| 为什么用 `F.cross_entropy` 而不手算 | 内部先减最大值防 exp 溢出、融合 log-sum-exp 更快、避免手写三步出错；数学等价 |
| 80/10/10 各自的用途 | Train 拟合参数（反复用）、Dev 调超参（适量用）、Test 最终报告（只用一次） |
| 初始 loss 的 sanity check | 理想初始 loss ≈ $\ln 27 \approx 3.296$；输出层用 randn 直接初始化时本课实测约 19.5，说明"过度自信" |
| 为什么用 Minibatch | 22 万样本全量太慢；32 个样本的噪声梯度换千倍更频繁的更新，噪声有助逃离局部最优 |
| 学习率搜索与衰减的做法 | 指数空间 0.001~1 试 1000 个值取 loss 最低点（约 0.1）；平稳后降到 0.01 再训练 |
| 过拟合 / 欠拟合的 loss 形态 | 双高 = 欠拟合；dev 远高于 train = 过拟合；train 2.1 / dev 2.2 健康；本课约 3500 参数 vs 22 万样本偏欠拟合 |
| 训练后的 embedding 散点图能看到什么 | 元音 a/e/i/o/u 聚成一簇、功能相近的辅音靠近、`.` 离群——模型自学出字符相似关系 |
