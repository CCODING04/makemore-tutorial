# 测验 · Part 3（训练诊断与 BatchNorm）

> 依据：本 Part 学习目标与教程正文。建议先完成作业再自测；每题附答案与教程锚点。

## 测验（5 题）

**Q1（数字）** 随机初始化的网络在训练前，初始 loss 应该是多少？不对时实测是多少，怎么修？

- **答案**：27 类均匀猜测的交叉熵 $-\ln(1/27) = \ln 27 \approx 3.29$——"我不知道"是最诚实的起点。未修正的 `randn` 初始化（输出层 W2、b2 都随机）使 logits 过大、softmax 尖锐"过于自信"，作业实测约 26.8（正常落在 20~30 区间）。修法：`W2 *= 0.01`、`b2 = 0`，修正后初始 loss 回落到约 3.29~3.30，省掉训练初期白跑的步数。
- **锚点**：教程 01_diagnosis.md §症状 1：初始 Loss 过高；assignment_3/README.md 题 1 / 题 2

**Q2（诊断）** 什么是 tanh 饱和？它为什么导致梯度消失？如何量化诊断？

- **答案**：tanh 输入绝对值大时输出贴近 ±1，局部梯度 $1 - \tanh^2(x)$ 趋近 0，反向传播信号被"掐断"，多层连乘后梯度完全消失。量化：统计 `(h.abs() > 0.97).float().mean()`（作业题 4 用 0.99 阈值）作为饱和比例；未修正初始化可超 40%，Kaiming 初始化后大幅下降；健康标准是各层饱和率 < 5%、std 接近、mean 接近 0。
- **锚点**：教程 01_diagnosis.md §症状 2：tanh 饱和；03_deep_network.md §工具 1：激活值分布；assignment_3 题 4

**Q3（概念）** Kaiming 初始化的公式是什么？背后的直觉与 gain 取值？

- **答案**：`W = torch.randn(fan_in, fan_out) * (gain / fan_in ** 0.5)`。直觉：fan_in 个输入做点积会使方差放大约 fan_in 倍，除以 $\sqrt{\mathrm{fan\_in}}$ 抵消放大，让每层输出方差 ≈ 输入方差，信号逐层既不爆炸也不消失。gain 依激活函数取值：ReLU 取 $\sqrt{2}$、tanh 取 5/3（约 1.67，课程所用）、线性取 1.0。
- **锚点**：教程 01_diagnosis.md §解药：Kaiming 初始化（含 gain 表）

**Q4（对比）** BatchNorm 的训练模式与评估模式行为有何不同？最常踩的 bug 是什么？

- **答案**：训练模式用当前 mini-batch 的均值方差做标准化，并用 EMA 更新 running 统计量（课程内联实现 `0.999 * running + 0.001 * batch`，等价 momentum=0.001；`nn.BatchNorm1d` 默认 momentum=0.1）；评估模式直接用 running 统计量且不再更新。头号 bug 是忘切 `model.eval()`——推理时还在用 batch 统计，batch_size=1 时 batch 方差为 0，标准化分母趋 0 直接 NaN。另外 gamma=1、beta=0 起步；BN 前的 `b1` 可置零省略（beta 已覆盖偏置功能）。
- **锚点**：教程 02_batchnorm.md §第三步：Running Mean/Var / §BN 的坑；assignment_3 题 3 思考

**Q5（诊断）** 深层网络训练的 4 种诊断工具分别看什么？其中最重要的指标和它的理想值是什么？

- **答案**：激活值分布（各层输出 std 接近、饱和率 < 5%）、梯度分布（各层梯度 std 接近，无突然缩小/放大）、梯度:数据比率（梯度相对参数大小，无极端值）、更新:数据比率（实际步长 `lr * p.grad.std() / p.data.std()`，最重要）。最后者的 log10 应在 -3 左右：太大训练不稳定，太小学得太慢；某条曲线远离 -3 就该调学习率或查初始化。诊断顺序：先看更新比率，再回溯梯度与激活。
- **锚点**：教程 03_deep_network.md §工具 4：更新/数据比率 / §4 种诊断工具总结

## 闪卡（正/背）

| 正面 | 背面 |
|---|---|
| 理想初始 loss 是多少 | $\ln 27 \approx 3.29$：27 类均匀猜测的交叉熵，"我不知道"的诚实起点 |
| 修初始 loss 的两行代码 | `W2 *= 0.01`（压 logits）、`b2 = 0`；softmax 输入趋零 → 输出趋均匀 |
| tanh 的导数 | $1 - \tanh^2(x)$；输出贴 ±1 时局部梯度趋 0，饱和即"神经元罢工" |
| 饱和比例怎么算 | `(h.abs() > 0.97).float().mean()`（作业口径 0.99）；未修正 > 40%，健康 < 5% |
| Kaiming 公式与 gain | 乘 `gain / fan_in ** 0.5`；tanh 5/3、ReLU $\sqrt{2}$、Linear 1.0 |
| BatchNorm 前向三步 | 减均值、除标准差（`sqrt(var + eps)`，eps=1e-5）→ gamma 缩放 + beta 平移；gamma=1、beta=0 起步 |
| running 统计量如何更新 | EMA：`0.999 * running + 0.001 * batch`（momentum=0.001）；eval 时用 running 且不再更新 |
| BatchNorm 三大坑 | 忘切 `model.eval()`；batch_size=1 方差为 0 → NaN；训练步数太少 running 未收敛（可用全量训练集重新校准） |
| 最重要诊断指标 | 更新:数据比率 log10 ≈ -3；太大不稳定、太小学得慢 |
| 为什么深层网络每层都跟 BN | Kaiming 只在初始化时管用，训练中分布会跑偏；BN 每一步自动矫正均值方差，是深层网络稳定的"积木" |
