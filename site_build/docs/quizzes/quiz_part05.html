Part 5: WaveNet - 层次化架构

选择题

1. WaveNet 相比简单 MLP 的主要优势是什么？

  • 参数更少
  • 可以处理更长的上下文
  • 训练更快
  • 不需要梯度
WaveNet 通过层次化的膨胀卷积，可以用更少的参数捕获更长距离的依赖关系。

2. FlattenConsecutive 层的作用是 ______。

答案：将相邻的 token embedding 拼接在一起
实现层次融合：每层将相邻 2 个 token 合并，逐层扩大感受野。

WaveNet 的核心思想是什么？
通过层次化的膨胀卷积（dilated convolution），逐层融合相邻 token，指数级扩大感受野。
什么是感受野？
模型能"看到"的输入范围。WaveNet 每层感受野翻倍：1→2→4→8→...
