Part 16: 图像/视频生成 - 扩散模型

选择题

1. DDPM 的前向过程是什么？

  • 从噪声生成图像
  • 逐步给图像加噪声
  • 去噪
  • 编码图像
前向过程逐步向图像添加高斯噪声，直到变成纯噪声。这是固定的马尔可夫链，不需要学习。

2. DDPM 的反向过程通过 ______ 学习去噪。

答案：预测噪声（noise prediction）
模型学习预测每步添加的噪声 ε，然后从当前状态减去预测的噪声，逐步还原图像。

3. 解释 Classifier-Free Guidance 的原理。

参考答案：
同时训练有条件和无条件生成，推理时将两者结合：output = uncond + scale × (cond - uncond)。scale > 1 增强条件控制，但可能降低多样性。

CFG 是 Stable Diffusion 等模型的关键技术。

什么是 IP-Adapter？
通过解耦的 Cross-Attention 将图像特征注入扩散模型，实现图像风格/内容控制，无需重新训练。
ControlNet 如何工作？
在 U-Net 旁添加条件分支，接收边缘图、深度图等条件，通过 zero convolution 注入主网络。
视频生成的主要挑战是什么？
1) 时间一致性（帧间连贯）；2) 计算成本（3D 卷积/注意力）；3) 长视频生成（误差累积）。
