Part 3: BatchNorm - 训练诊断与优化

选择题

1. Kaiming 初始化的核心思想是什么？

  • 让所有权重为 1
  • 保持每层输出的方差稳定
  • 让梯度为 0
  • 随机初始化权重
Kaiming 初始化通过缩放权重（gain/√fan_in），确保信号在深层网络中传播时方差保持稳定，避免梯度消失或爆炸。

2. BatchNorm 的 running_mean 和 running_var 在什么时候使用？

  • 训练时
  • 推理时
  • 永远不用
  • 只在第一层使用
训练时使用 batch 统计量并更新 running stats，推理时使用 running_mean 和 running_var（固定值）。

3. tanh 激活函数的 Kaiming gain 值是 ______。

答案：5/3
对于 tanh 激活函数，Kaiming gain = 5/3 ≈ 1.667，用于补偿 tanh 的非线性压缩效应。

4. 解释 BatchNorm 的 momentum 参数含义。

参考答案：
momentum 控制 running stats 的更新速度：running = (1-momentum) * running + momentum * batch_stat。momentum=0.1（PyTorch 默认）更新较快，momentum=0.001 更新较慢但更平滑。

EMA 时间常数 τ = 1/momentum，约 3-5τ 后收敛。

什么是 BatchNorm？
对每个 mini-batch 的激活值进行归一化（减均值除标准差），再用可学习的 γ/β 缩放偏移。
为什么需要 BatchNorm？
1) 稳定训练；2) 允许更大学习率；3) 减少对初始化的敏感度；4) 轻微正则化效果。
训练和推理时 BatchNorm 的区别？
训练：用 batch 均值/方差，更新 running stats；推理：用固定的 running_mean/running_var。
