📌 这张图画什么

self-attention 的一轮计算：句子里的每个 token 都会轮流当一次"提问者"（查询 q），拿自己的问题去和所有位置的"标签"（键 k）对账，算出相关性权重，再按权重把全句的"内容"（值 v）汇总成自己的新表示。动画把这一轮拆成 4 个阶段 × 8 个提问者 = 32 帧。

🔖 符号与标识符

Q / q查询（question）：该 token"在找什么样的信息"。橙色高亮的框 = 当前提问者
K / k键（key）：每个位置对外暴露的"标签/索引"，供 q 来比对
V / v值（value）：每个位置真正要被搬运的"内容"
wij注意力权重：qi 分给 kj 的比例，softmax 保证每行加和 = 1
√d_k缩放因子：点积方差随维度 d_k 增大，除以 √d_k 防止 softmax 饱和（课程实测 std 15.9→0.99）
⟨bos⟩序列起始符：没有上文可看，注意力 100% 给自己
