PPO 视角提醒

  • 这张图是 GRPO 视角的三角色
  • PPO（adv_estimator=gae）还需第 4 个角色 critic
  • GRPO 砍掉 critic 正是它省显存的原因

为什么要有 weight sync

  • 训练态（FSDP2 分片）与推理态（vLLM）格式不同
  • 每步把新权重刷进推理引擎再采样
  • HybridEngine 让这一步不用重载整个模型
