选择题

1. GRPO 中"组内标准化优势"的作用是什么？

  • 增加奖励值
  • 减少方差，稳定训练
  • 加速收敛
  • 减少参数
对同一 prompt 的多个采样计算相对优势（减均值除标准差），减少奖励尺度的影响。

2. 解释 RLVR（Reinforcement Learning with Verifiable Rewards）。

参考答案：
使用可验证的规则作为奖励（如数学题的答案是否正确），而非学习的奖励模型。优点是无需标注偏好数据，缺点是只适用于有标准答案的任务。

RLVR 是 GRPO 的典型应用场景，DeepSeek-Math 首创。

verl 框架的三角色是什么？
Actor（策略模型）、Critic（价值模型，GRPO 可选）、Reference（参考模型，计算 KL）。
什么是 KL 散度约束？
限制策略模型与参考模型的差异，防止 reward hacking。KL = Σ π_ref(y|x) * log(π_ref(y|x) / π(y|x))。
