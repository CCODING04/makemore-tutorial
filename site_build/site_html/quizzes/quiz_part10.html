选择题

1. DDP（分布式数据并行）的核心思想是什么？

  • 把模型切到不同 GPU
  • 每个 GPU 持有完整模型，数据不同
  • 只在 CPU 上训练
  • 使用单卡训练
DDP 中每个 GPU 持有完整的模型副本，处理不同的数据子集，通过 All-Reduce 同步梯度。

2. ZeRO 的三个阶段分别优化 ______、______、______。

答案：优化器状态、梯度、参数
ZeRO-1: 分片优化器状态；ZeRO-2: +分片梯度；ZeRO-3: +分片参数。每个阶段减少显存占用。

3. 解释张量并行（Tensor Parallelism）的原理。

参考答案：
将矩阵乘法拆分到多个 GPU：例如将权重矩阵按列切分，每个 GPU 计算部分结果，再通过 All-Gather 合并。适合单层很大的模型（如 70B）。

Megatron-LM 风格的张量并行：行切分和列切分交替使用，最小化通信。

All-Reduce 操作的作用是什么？
将所有 GPU 的梯度求和/求平均，并将结果广播到所有 GPU，保证参数同步。
什么是流水线并行（Pipeline Parallelism）？
将模型按层切分到不同 GPU，通过 micro-batch 流水线执行，减少气泡（bubble）。
FSDP 和 ZeRO-3 的关系？
FSDP（Fully Sharded Data Parallel）是 PyTorch 对 ZeRO-3 的实现，将参数、梯度、优化器状态全部分片。
