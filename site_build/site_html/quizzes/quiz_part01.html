Part 1: Bigrams - 最简单的语言模型

选择题

1. Bigram 模型的基本思想是什么？

  • 只看前一个字符预测下一个字符
  • 看所有前文预测下一个字符
  • 随机生成字符
  • 使用神经网络预测
Bigram 模型只依赖前一个字符（一阶马尔可夫假设），通过统计条件概率来预测下一个字符。

2. 为什么使用负对数似然（NLL）作为损失函数？

  • 因为它计算简单
  • 因为它可以将概率最大化转化为损失最小化
  • 因为它总是正数
  • 因为它不需要梯度
NLL 将概率最大化问题（max P）转化为损失最小化问题（min -log P），便于使用梯度下降优化。

3. 对于 27 个字符的词汇表，均匀分布的初始 loss 约等于 ______。

答案：ln(27) ≈ 3.296
当模型对所有字符均匀预测时，每个字符概率为 1/27，loss = -ln(1/27) = ln(27) ≈ 3.296。

4. 解释 Laplace 平滑的作用和原理。

参考答案：
Laplace 平滑通过给每个计数加 1（N+1），避免零概率问题。原理：即使某个 bigram 从未出现，也不会得到概率 0，保证模型能生成所有可能的字符。

零概率会导致 log(0) = -∞，使训练崩溃。平滑后所有字符都有非零概率。

什么是 Bigram 模型？
只看前一个字符来预测下一个字符的简单语言模型，基于条件概率统计。
NLL 损失函数的公式是什么？
NLL = -Σ log(P(target))，其中 P(target) 是模型对正确字符的预测概率。
为什么初始 loss 应该约等于 ln(vocab_size)？
因为随机初始化时模型对所有字符均匀预测，每个字符概率为 1/vocab_size，loss = -ln(1/vocab_size) = ln(vocab_size)。
