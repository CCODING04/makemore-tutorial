Part 14: 推理部署 - vLLM

选择题

1. vLLM 的 PagedAttention 解决了什么问题？

  • 训练速度
  • KV Cache 内存碎片化
  • 模型精度
  • 数据加载
PagedAttention 将 KV Cache 分成固定大小的页，按需分配，避免预分配导致的内存浪费（从 60-80% 降到 <4%）。

2. TTFT 是 ______ 的缩写，表示 ______。

答案：Time To First Token，首 token 延迟
TTFT 衡量从请求到生成第一个 token 的时间，反映 prefill 阶段的效率。

3. 解释投机解码（Speculative Decoding）的原理。

参考答案：
用小模型快速生成多个候选 token，大模型一次性验证。如果候选被接受，节省了多次大模型推理；如果不接受，从分歧点重新生成。加速比取决于接受率 α。

课程实测：α≈0.65 时，实测 2.81 tokens/cycle vs 理论 2.53。

什么是连续批处理（Continuous Batching）？
不等一个 batch 全部完成，而是有请求就加入、完成就退出，提高 GPU 利用率。
KV Cache 的显存怎么算？
KV 显存 = 2 × n_layers × n_heads × d_head × seq_len × dtype_size。例如 LLaMA-7B fp16 seq2048 ≈ 1.07GB。
GQA 如何减少 KV Cache？
多个 Q head 共享同一组 KV head。例如 KV heads=8（vs Q heads=32），KV Cache 减少 4 倍。
