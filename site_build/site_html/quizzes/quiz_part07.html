选择题

1. RoPE（旋转位置编码）的核心思想是什么？

  • 给每个位置一个可学习的向量
  • 通过旋转矩阵编码相对位置
  • 使用正弦余弦函数
  • 添加随机噪声
RoPE 通过旋转 Q 和 K 向量，使内积自然包含相对位置信息，且支持长度外推。

2. GQA（分组查询注意力）相比 MHA 的优势是什么？

  • 更准确
  • 减少 KV Cache 显存
  • 训练更快
  • 参数更少
GQA 让多个 Q head 共享同一组 KV head，减少推理时 KV Cache 的显存占用。

3. RMSNorm 相比 LayerNorm 去掉了 ______ 和 ______。

答案：均值中心化（减均值）和 bias（偏置项）
RMSNorm 只用均方根（RMS）归一化，省去减均值和 bias，计算更快且效果相当。

4. 解释 DPO 的核心思想。

参考答案：
DPO 直接从偏好数据学习，无需训练奖励模型。通过 Bradley-Terry 模型将偏好转化为 loss，隐式优化 RLHF 目标。

DPO 公式：loss = -log(σ(β·(log π(y_w)/π_ref(y_w) - log π(y_l)/π_ref(y_l))))

什么是 KV Cache？
推理时缓存已计算的 K 和 V，避免重复计算，使生成每个新 token 只需计算当前 token 的 Q。
SwiGLU 激活函数的公式是什么？
SwiGLU(x) = (x @ W_gate) * swish(x @ W_up) @ W_down，其中 swish(x) = x * sigmoid(x)。
MoE（混合专家）如何工作？
路由器（Router）为每个 token 选择 top-k 个专家，只激活选中的专家，实现稀疏激活。
