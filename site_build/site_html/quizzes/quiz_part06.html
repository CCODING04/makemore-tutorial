选择题

1. Self-Attention 的核心计算是什么？

  • 矩阵加法
  • Q @ K^T / √d_k → softmax → @ V
  • 卷积运算
  • 循环递归
Self-Attention：计算 Query 和 Key 的相似度，归一化后加权聚合 Value。

2. 为什么 Attention 要除以 √d_k？

  • 为了简化计算
  • 为了防止 softmax 饱和
  • 为了减少参数
  • 为了加速训练
当 d_k 较大时，Q@K^T 的方差会很大，导致 softmax 输出接近 one-hot（梯度消失）。除以 √d_k 使方差稳定在 1 附近。

3. Multi-Head Attention 中，每个 head 的维度是 ______。

答案：d_model / n_heads
例如 d_model=512, n_heads=8，则每个 head 的维度是 64。

4. 解释 LayerNorm 和 BatchNorm 的区别。

参考答案：
BatchNorm 沿 batch 维度归一化（依赖 batch size），LayerNorm 沿特征维度归一化（不依赖 batch size）。Transformer 使用 LayerNorm 因为序列长度可变，batch 统计不稳定。

LayerNorm 对每个样本独立归一化，适合变长序列。

Self-Attention 的三个矩阵 Q, K, V 分别代表什么？
Q (Query): 我在找什么；K (Key): 我有什么特征；V (Value): 我的实际内容。
什么是残差连接（Residual Connection）？
将层的输入直接加到输出：output = x + f(x)。解决深层网络的梯度消失问题。
为什么 Transformer 使用 learned positional embedding？
因为 Self-Attention 是置换不变的（permutation invariant），需要位置信息来区分 token 顺序。
