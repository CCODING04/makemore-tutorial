DDPM 噪声调度：β 与 ᾱ 的形状决定"加噪的节奏"

x_t = √ᾱ_t·x₀ + √(1-ᾱ_t)·ε。调总步数 T、调度方式（linear/cosine）、β_max，看每步噪声 β_t 与信号存活 ᾱ_t 的曲线如何变形。
β_t（每步新加噪声强度）ᾱ_t（原始信号存活比例）√ᾱ_t（数据成分系数）

📌 这张图画什么

前向加噪不是一步到位，而是 T 步小噪声的连乘。这张图回答"每一步加多猛、信号什么时候死"：β_t 是每一步新加的噪声强度，ᾱ_t 是从第 1 步连乘到 t 的信号存活率。调度（β 的排班方式）直接影响：末端噪声够不够"纯"、中段学习信号是否均匀。

🔖 符号与标识符

β_t第 t 步新加的高斯噪声方差（linear 下从 1e-4 升到 β_max）
ᾱ_t∏(1-β) 连乘——t 时刻原始信号 x₀ 的存活比例，单调递减
√ᾱ_t / √(1-ᾱ_t)闭式公式里"留多少数据 / 混多少噪声"的两个系数
linear / cosine两种排班：linear 末端衰减过猛（ᾱ 掉太快）；cosine 按余弦排班，中段更均匀
T总步数——训练/生成都要走 T 步（越大越细腻也越贵）

🧭 试一试

  • 本课预设（400 线性）：ᾱ_T 降到 ≈0.001 以下，√ᾱ_T→0 即 x_T≈纯噪声——验证采样起点假设
  • 切 cosine：同 T 下中段 ᾱ 衰减更均匀——这是它改善细节生成的原因
  • 把 β_max 拖到最小（0.005）：同样的 T，末端 ᾱ_Т 还很高——"加噪不到位"，网络学不到纯噪声端的去噪
  • 对照课程：脚本用 β 1e-4→0.02 线性、T=400，与预设一致
