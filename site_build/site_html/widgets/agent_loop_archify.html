Part 19 · Agent 与 FC

Agent Loop while 循环就是全部骨架

五个部件连成一个循环：parse 出"有调用"就执行工具、把结果贴回 messages、回到 ② 进入下一轮；"无调用"才输出最终答案。② 每轮都会重新执行。悬停 ② 看整条循环；安全边界（白名单/超时）都在执行侧。

循环体
②③④⑤
生成 → 解析 → 执行 → 回填
出口
2 个
无调用=答案；或触发终止条件
终止条件
3 个
无调用 / max_turns / 复读检测

循环骨架与两个出口

Archify 规格 → 定制模板
Agent 运行时（①②③） 工具执行（④） 对话状态（⑤ messages） 出口（答案） 常速流动 = 循环运转（不表示先后）

循环本质

  • 把工具结果拼回上下文，再让模型决定下一步
  • 全部智能在"决定下一步"里，其余是电话线路
  • 工具 schema 塞进 prompt——模型"说话"或"填单"

三个终止条件

  • ① 无 tool_calls（答案 / 放弃）
  • ② max_turns 上限
  • ③ 同调用复读 3 次（循环检测）

安全边界

  • 模型只能"下单"（name + arguments JSON）
  • 超时 / 白名单 / 路径检查都在执行侧
  • 模型输出是不可信输入——边界必须放执行侧
