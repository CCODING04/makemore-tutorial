Transformer Block x = x + f(x)

残差流主干从输入直通输出——x 只经过加法；两个子层从主干上读 x、算出增量再写回：x = x + self.sa(self.ln1(x))，x = x + self.ffwd(self.ln2(x))（Pre-LN）。两个 ⊕ 是同步点：两路输入都到达后才输出，支路并行、没有先后。

核心公式
x + f(x)
主干只做加法 · 子层只添增量
子层分工
① 通信 → ② 计算
Self-Attention · FeedForward
⊕ 同步点
两路到齐才输出
x 与 f(x) 并行汇合，无先后

Block 内部结构 · 残差主干 + 两条支路

Archify 规格 → 定制模板
⊕ 残差汇合点（同步：两路到齐才输出） ① 通信支路（Attention） ② 计算支路（FFN） 残差流主干（x 只经加法） 常速流动 = 数据流（不表示先后）

为什么梯度能直通

  • 加法把上游梯度原样复制给两路，不是对半分
  • 恒等支路梯度恒为 1：主干梯度不衰减（Part 4）
  • 初始化时子层很小 → 深层也能训练

Pre-LN 顺序别写反

  • 先归一化再进子层：x + sa(ln1(x))
  • 写成 ln(x + sa(x)) 是 post-norm
  • LN 在支路上、不在主干上——主干只做加法

堆叠成深层网络

  • Block 重复 n_layer 次，输出直进下一层
  • 现代 LLM 把 ReLU MLP 换成 SwiGLU（Part 7）
  • 先通信、再计算是每个 Block 的固定节奏
