LSH 分带 S 曲线：召回与误报的一根旋钮

公式 P(候选) = 1-(1-J^r)^b。拖动 b（band 数）、r（每 band 行数）、J（文档对真实相似度），实时看 S 曲线形状与当前文档对的命中概率。

📌 这张图画什么

横轴是两篇文档真实的 Jaccard 相似度 J，纵轴是它们被分带 LSH 判为"候选对"的概率。曲线越陡，筛选越"一刀切"：拐点 J* 右边的对几乎必命中（高召回），左边的对几乎必落选（低误报）。去重管线的第一道闸门就是这条曲线。

🔖 符号与标识符

J两文档 shingle 集合的 Jaccard 相似度（真实值，未知、待估计）
b签名被切成的 band（段）数——越大越"宽进"：召回↑、误报↑
r每个 band 内的行数——越大越"严出"：误报↓、漏检↑
J* = (1/b)^(1/r)S 曲线拐点 = "等效阈值"：J 高于它大概率命中，低于它大概率被滤掉
k = b×r签名总维度（哈希函数个数）预算——b 与 r 此消彼长
