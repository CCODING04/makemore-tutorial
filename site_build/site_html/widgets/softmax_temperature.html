Softmax 温度：采样前给概率分布"调焦"

5 个候选 token（固定 logits [2.0, 1.5, 0.5, 0.0, -1.0]），拖动温度 T 看概率分布如何从"几乎必选第一名"平滑到"人人有份"。

📌 这张图画什么

语言模型每步输出的不是"一个词"而是整个词表上的分数（logits）。采样前要用 softmax 把分数变成概率分布——温度 T 决定这个分布的"尖锐程度"：T→0 逼近贪心（永远选最高分），T 越大分布越平（低概率词也常被采到）。聊天产品的"创造性"旋钮调的就是它。

🔖 符号与标识符

z（logit）模型对每个候选 token 的原始打分（未归一化）
T温度：z 先除以 T 再进 softmax。T<1 使差距放大、T>1 使差距缩小
pitoken i 的采样概率 = exp(z_i/T) / Σ exp(z_j/T)
熵分布的"不确定度"（nat）：均匀 5 选 1 时 = ln5 ≈ 1.61；越低越确定
贪心T→0 的极限：永远取 argmax，零随机性（可复现但呆板）

🧭 试一试

  • 拖到 T=0.05：A 的概率 ≈100%，熵≈0——"贪心解码"，面试答"为什么你的输出每次一样"就是它
  • 拖到 T=2：注意最后一名 E（logit −1）也拿到可观概率——高温会让模型"跑飞"，工业上常配 top-p 截断
  • 对比 T=1 与 T=0.3 的熵读数：低温把不确定性"挤"了出去——代价是多样性
  • 课程锚点：P1 训练用的就是 T=1 的标准 softmax；采样阶段才引入温度
