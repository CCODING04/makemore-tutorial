Self-Attention：一轮"提问 → 对账 → 加权汇总"

句子 "⟨bos⟩ the cat sat on the mat ."（8 个 token）的一层 self-attention。用 ◀| 与 |▶ 逐帧看每个 token 如何收集全文信息。
速度

📌 这张图画什么

self-attention 的一轮计算：句子里的每个 token 都会轮流当一次"提问者"（查询 q），拿自己的问题去和所有位置的"标签"（键 k）对账，算出相关性权重，再按权重把全句的"内容"（值 v）汇总成自己的新表示。动画把这一轮拆成 4 个阶段、8 个提问者，共 32 帧。

🔖 符号与标识符

Q / q查询（question）：该 token"在找什么样的信息"。橙色高亮的行 = 当前提问者
K / k键（key）：每个位置对外暴露的"标签/索引"，供 q 来比对
V / v值（value）：每个位置真正要被搬运的"内容"
wij注意力权重：qi 分给 kj 的比例，softmax 保证每行加和 = 1
√d_k缩放因子：点积方差随维度 d_k 增大，除以 √d_k 防止 softmax 饱和（课程实测 std 15.9→0.99）
⟨bos⟩序列起始符：没有上文可看，注意力 100% 给自己

🧭 试一试

  • 连续按 |▶：先看 q="sat" 的四阶段——它把最大权重给了 "cat"（0.55，谁坐在地上？）
  • 再逐帧到 q="the"（第 6 个，"the mat" 里那个限定词）：它同时回看 "the"(0.30) 和 "cat"(0.35)——名词短语整体参与
  • 注意 q="⟨bos⟩" 那帧：因果 mask 下它没有任何邻居，权重全给自己（1.00）——这就是 decoder-only 的"第一帧孤独"
  • 拖进度条随机跳帧，观察：权重行的每一行加和永远是 1.00
