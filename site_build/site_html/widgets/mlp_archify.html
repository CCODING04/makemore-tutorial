课程第一张完整网络图：3 个字符索引经 C 查表得到向量、拼接成 6 维，经 W1(6→100) + tanh 再 W2(100→27)，softmax 给出下一个字符的概率。悬停蓝色节点看要训练的参数在哪。

100 维
tanh 激活（Bengio 2003 设置）
输出
27 类概率
softmax(logits) → 下一字符

前向形状链

Archify 规格 → 定制模板
可训练参数（悬停高亮） 运算层（拼接 / 激活） 输出概率 网络结构 数据流

参数在哪

  • C、W1、W2 是要训练的参数
  • C 创建时必须 requires_grad=True
  • 漏掉会在 loss.backward() 直接报错

形状链

  • (N,3) → 查表 (N,3,2) → 拼接 (N,6)
  • Linear 6→100 → tanh → Linear 100→27
  • 输出 logits (N,27) 经 softmax 成概率

C[X] 高级索引

  • emb = C[X]：按索引行取出向量
  • 这是 Part 2 最核心的操作之一
  • 查表对梯度可导——梯度回传到 C 的对应行
