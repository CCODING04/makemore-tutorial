Part 12: 微调实战 - LLaMA-Factory/LoRA

选择题

1. LoRA 的核心思想是什么？

  • 全参数微调
  • 低秩分解注入
  • 冻结所有层
  • 只训练最后一层
LoRA 冻结预训练权重，只训练低秩分解的 A 和 B 矩阵（W' = W + B×A），大幅减少可训练参数。

2. QLoRA 相比 LoRA 额外引入了 ______ 和 ______ 技术。

答案：NF4 量化和双量化
QLoRA 将基础模型量化到 4-bit（NF4），并用双量化进一步压缩量化参数，减少显存占用。

3. 为什么 LoRA 的 B 矩阵要零初始化？

参考答案：
B 零初始化保证第一步 W' = W + B×A = W，即初始时模型与原模型完全相同，训练从原模型出发，避免随机扰动破坏预训练知识。

如果 B 不为零，初始时 W' ≠ W，模型行为会突变，可能导致训练不稳定。

LoRA 的参数量怎么算？
每个线性层增加 2 × rank × d 参数（A: d×rank, B: rank×d）。例如 rank=8, d=4096，增加 65K 参数。
什么时候用 LoRA，什么时候用全参微调？
LoRA: 资源有限、快速实验、数据少；全参: 数据充足、追求最佳效果、任务与预训练差异大。
DPO-LoRA 是什么？
用 LoRA 做 DPO 微调：同时训练策略模型和参考模型的 LoRA adapter，参考模型权重冻结。
