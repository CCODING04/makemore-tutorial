Part 2: MLP - 多层感知机

选择题

1. Embedding 层的作用是什么？

  • 将连续向量转为离散索引
  • 将离散字符映射为连续向量
  • 进行特征归一化
  • 实现注意力机制
Embedding 通过查表将离散的字符索引映射为连续的稠密向量表示。

2. 为什么要划分 train/dev/test 三个数据集？

  • 为了增加数据量
  • 为了防止用"考卷"调参导致过拟合测试集
  • 为了加快训练速度
  • 为了减少内存占用
train 用于训练，dev 用于选模型和调参，test 只在最终评估时使用一次，防止间接过拟合测试集。

3. MLP 中，将多个字符的 embedding 拼接在一起的操作是 ______。

答案：emb.view(emb.shape[0], -1) 或 torch.cat
将 (N, block_size, n_embd) 的 embedding 张量 reshape 为 (N, block_size * n_embd)，送入全连接层。

4. 解释 block_size 对模型性能的影响。

参考答案：
block_size 越大，模型能看到更多上下文，性能通常更好（如 3→5 可降低 dev loss）。但输入维度线性增长（block_size × n_embd），计算成本增加，且收益递减。

课程实验：block_size 从 3 增加到 5，dev loss 从约 2.3 降到约 2.1。

Embedding 和 one-hot + 矩阵乘法的关系？
数学等价：C[X] 等价于 one_hot(X) @ C，但查表更高效，无需构造稀疏的 one-hot 向量。
什么是 block_size？
上下文窗口大小，即模型一次能看到的前文字符数量。block_size=3 表示看前 3 个字符。
train/dev/test 三份数据各自的用途？
train: 训练模型；dev: 选择超参和模型；test: 最终一次性评估。
